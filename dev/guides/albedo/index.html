    Albedo¶

    Evaluate a Synthetic Albedo Without Heights¶

    A synthetic albedo is a base color in hue, saturation and value, optionally varied by fractal noise in each channel, for terrain without albedo data. It needs no heights, so any grid can be evaluated, here into three bands, red, green and blue, of a warm tint whose brightest band is 0.11.

    source = terraingen.SyntheticAlbedo(value=0.11, rgb=True, hue_deg=30.0, saturation=0.25)
grid = terraingen.RasterGrid.centered((0.0, 0.0), (100.0, 100.0), 0.5)  # meters
red, green, blue = terraingen.evaluate_albedo(terraingen.Albedo(source), grid)

    SyntheticAlbedoOptions options;
options.value = 0.11;
options.rgb = true;
options.hueDegrees = 30.0;
options.saturation = 0.25;
Albedo albedo;
albedo.source = std::make_shared<SyntheticAlbedo>(options);
const RasterGrid grid = RasterGrid::Centered({0.0, 0.0}, {100.0, 100.0}, 0.5);  // meters
const std::vector<Raster<float>> bands = EvaluateAlbedo(albedo, grid, {});  // red, green, blue

    Add Noise to a Synthetic Albedo¶

    Each channel of a synthetic albedo can be varied by a stack of fractals. Value noise is relative, so an amplitude of 0.5 makes the value swing up to half of itself either way, while hue noise is in degrees and saturation noise in saturation. Broad noise in hue and saturation with finer noise in value gives a tinted ground with patches of darker and brighter soil.

    source = terraingen.SyntheticAlbedo(
    value=0.11,
    value_noise=[terraingen.Fractal(seed=1, wavelength=120.0, amplitude=0.5)],
    rgb=True,
    hue_deg=30.0,
    saturation=0.25,
    hue_noise_deg=[terraingen.Fractal(seed=2, wavelength=200.0, amplitude=15.0)],
    saturation_noise=[terraingen.Fractal(seed=3, wavelength=200.0, amplitude=0.1)],
)
grid = terraingen.RasterGrid.centered((0.0, 0.0), (400.0, 400.0), 2.0)  # meters
red, green, blue = terraingen.evaluate_albedo(terraingen.Albedo(source), grid)

    SyntheticAlbedoOptions options;
options.value = 0.11;
options.valueNoise = {Fractal::Fbm(1, 120.0, 0.5)};
options.rgb = true;
options.hueDegrees = 30.0;
options.saturation = 0.25;
options.hueNoiseDegrees = {Fractal::Fbm(2, 200.0, 15.0)};
options.saturationNoise = {Fractal::Fbm(3, 200.0, 0.1)};
Albedo albedo;
albedo.source = std::make_shared<SyntheticAlbedo>(options);
const RasterGrid grid = RasterGrid::Centered({0.0, 0.0}, {400.0, 400.0}, 2.0);  // meters
const std::vector<Raster<float>> bands = EvaluateAlbedo(albedo, grid, {});  // red, green, blue

    Evaluate the Albedo of a Configuration Without Heights¶

    A configuration's albedo is a source of starting values changed by albedo layers, here fresh craters brightened above a synthetic base. BuildAlbedo builds it for the terrain built from the same configuration, whose crater layers it reads. Layers that depend only on craters need no heights, so the albedo is evaluated over any grid alone.

    config = terraingen.TerrainGenConfig.from_dict(
    {
        "schema_version": 1,
        "layers": [{"type": "craters", "min_diameter_m": 3, "max_diameter_m": 40}],
        "albedo": {"source": {"type": "synthetic", "value": 0.12}, "layers": [{"type": "craters"}]},
    }
)
terrain = terraingen.build_terrain(config)
albedo = terraingen.build_albedo(config, terrain)
grid = terraingen.RasterGrid.centered((0.0, 0.0), (100.0, 100.0), 0.5)  # meters
(bands,) = terraingen.evaluate_albedo(albedo, grid)  # one band, the synthetic value

    const TerrainGenConfig config = ParseConfig(R"({
    "schema_version": 1,
    "layers": [{"type": "craters", "min_diameter_m": 3, "max_diameter_m": 40}],
    "albedo": {"source": {"type": "synthetic", "value": 0.12}, "layers": [{"type": "craters"}]}
})");
const Terrain terrain = BuildTerrain(config);
const Albedo albedo = BuildAlbedo(config, terrain);
const RasterGrid grid = RasterGrid::Centered({0.0, 0.0}, {100.0, 100.0}, 0.5);  // meters
const std::vector<Raster<float>> bands = EvaluateAlbedo(albedo, grid, {});

    Upscale an Albedo Map With Fractal Detail¶

    An albedo map, such as a normal albedo mosaic from orbit, starts an albedo as RasterAlbedo. It is interpolated to the grid and given detail below its cells, fractal noise that continues the map's own measured roughness to finer scales. Here a 10 m map read from a GeoTIFF is evaluated at 0.5 m. Outside the map the albedo is NaN.

    coarse = terraingen.read_geotiff(folder / "albedo.tif")  # 10 m cells
options = terraingen.RasterAlbedoOptions(
    method=terraingen.ResampleMethod.CUBIC, detail=terraingen.AlbedoDetail(seed=1, octaves=4)
)
source = terraingen.RasterAlbedo([coarse], options)
grid = terraingen.RasterGrid.centered((0.0, 0.0), (160.0, 160.0), 0.5)  # meters
(bands,) = terraingen.evaluate_albedo(terraingen.Albedo(source), grid)

    const GeoTiff map = ReadGeoTiff(path);  // 10 m cells
RasterAlbedoOptions options;
options.method = ResampleMethod::Cubic;
options.detail.seed = 1;
options.detail.octaves = 4;
Albedo albedo;
albedo.source = std::make_shared<RasterAlbedo>(std::vector<Raster<float>>{map.raster}, options);
const RasterGrid grid = RasterGrid::Centered({0.0, 0.0}, {160.0, 160.0}, 0.5);  // meters
const std::vector<Raster<float>> bands = EvaluateAlbedo(albedo, grid, {});

    Fade Crater Rays and Ejecta With Age¶

    CraterAlbedo brightens the interiors, ejecta and rays of a crater layer's fresh craters by their optical maturity, with Tycho's values by default. The bright material fades over a retention time set by the crater's diameter, 5 Myr for craters up to 1 km, so a crater 3 Myr old keeps only faint rays. Crater albedo needs no heights.

    craters = terraingen.CraterLayer.manual(
    [
        terraingen.Crater(-900.0, 0.0, 400.0, age_gyr=0.0),
        terraingen.Crater(900.0, 0.0, 400.0, age_gyr=0.003),  # 3 Myr of a 5 Myr retention
    ]
)
rays = terraingen.CraterAlbedo(craters, terraingen.CraterAlbedoOptions(seed=2))
albedo = terraingen.Albedo(terraingen.SyntheticAlbedo(value=0.11), [rays])
grid = terraingen.RasterGrid.centered((0.0, 0.0), (3600.0, 1800.0), PIXEL)  # meters
(bands,) = terraingen.evaluate_albedo(albedo, grid)

    const auto craters = CraterLayer::Manual({
    ManualCrater(-900.0, 0.0, 400.0),
    ManualCrater(900.0, 0.0, 400.0).AgeGyr(0.003),  // 3 Myr of a 5 Myr retention
});
CraterAlbedoOptions options;
options.seed = 2;
Albedo albedo;
albedo.source = std::make_shared<SyntheticAlbedo>(SyntheticAlbedoOptions{});
albedo.layers = {std::make_shared<CraterAlbedo>(craters, options)};
const RasterGrid grid = RasterGrid::Centered({0.0, 0.0}, {3600.0, 1800.0}, 10.0);  // meters
const std::vector<Raster<float>> bands = EvaluateAlbedo(albedo, grid, {});

    Brighten Steep Slopes as Fresher Soil¶

    Downslope creep keeps exposing immature soil on steep ground, so SlopeAlbedo raises the optical maturity of slopes past an onset, 20 degrees by default, and the albedo with it. It reads slopes on the terrain's heights, so the evaluation is given the ground beneath every layer. Without a ground the albedo is left alone.

    slopes = terraingen.SlopeAlbedo(terraingen.SlopeAlbedoOptions(onset_deg=20.0))
albedo = terraingen.Albedo(terraingen.SyntheticAlbedo(value=0.11), [slopes])
heights = terrain.evaluate()
grid = heights.grid
(bands,) = terraingen.evaluate_albedo(albedo, grid, ground=terrain)  # slopes read on terrain

    SlopeAlbedoOptions options;
options.onsetDegrees = 20.0;
Albedo albedo;
albedo.source = std::make_shared<SyntheticAlbedo>(SyntheticAlbedoOptions{});
albedo.layers = {std::make_shared<SlopeAlbedo>(options)};
LayerContext context;
context.ground = &terrain;  // after every layer
const RasterGrid grid = terrain.Evaluate().Grid();
const std::vector<Raster<float>> bands = EvaluateAlbedo(albedo, grid, context);

    Brighten the Albedo With Rocks¶

    Rock is brighter than mature regolith, 2.5 times by default. RockAlbedo brightens each sample by the share of it the boulders of a boulder layer cover, read on the ground beneath that layer. Rocks too small to resolve add a speckle with the mean and variance of the cover they would give.

    rocks = terraingen.RockAlbedo(
    terraingen.RockAlbedoOptions(seed=1, reflectance_ratio=2.5), terrain, layers=[0]
)
albedo = terraingen.Albedo(terraingen.SyntheticAlbedo(value=0.11), [rocks])
grid = terrain.evaluate().grid
(bands,) = terraingen.evaluate_albedo(albedo, grid, ground=terrain)

    RockAlbedoOptions options;
options.seed = 1;
options.reflectanceRatio = 2.5;
RockSource rocks;
rocks.layer = boulders;
// Beneath the boulder layer, layer 0.
rocks.ground = std::make_shared<const Terrain>(terrain.Beneath(0));
Albedo albedo;
albedo.source = std::make_shared<SyntheticAlbedo>(SyntheticAlbedoOptions{});
albedo.layers = {std::make_shared<RockAlbedo>(options, std::vector<RockSource>{rocks})};
const RasterGrid grid = terrain.Evaluate().Grid();
const std::vector<Raster<float>> bands = EvaluateAlbedo(albedo, grid, {});

    Scatter Dark and Bright Splotches¶

    Splotches are the small dark and bright patches that low-velocity secondary impacts leave in loose regolith, forming and fading over tens of thousands of years. SplotchAlbedo scatters them by the measured formation rate, nine in ten dark by default. Here half are bright, and only those at least 3 m across are drawn, to keep the ground between them clear.

    options = terraingen.SplotchAlbedoOptions(seed=3, dark_share=0.5, bright_share=0.5, min_diameter=3.0)
albedo = terraingen.Albedo(terraingen.SyntheticAlbedo(value=0.11), [terraingen.SplotchAlbedo(options)])
grid = terraingen.RasterGrid.centered((0.0, 0.0), (100.0, 100.0), PIXEL)  # meters
(bands,) = terraingen.evaluate_albedo(albedo, grid)

    SplotchAlbedoOptions options;
options.seed = 3;
options.darkShare = 0.5;
options.brightShare = 0.5;
options.minDiameter = 3.0;  // meters
Albedo albedo;
albedo.source = std::make_shared<SyntheticAlbedo>(SyntheticAlbedoOptions{});
albedo.layers = {std::make_shared<SplotchAlbedo>(options)};
const RasterGrid grid = RasterGrid::Centered({0.0, 0.0}, {100.0, 100.0}, 0.25);  // meters
const std::vector<Raster<float>> bands = EvaluateAlbedo(albedo, grid, {});

    Add Reflectance Zones Around a New Crater¶

    New craters up to about 50 m across leave reflectance zones that LROC before and after images show, a bright proximal zone, a dark one beyond it and faint finger-like distal zones reaching a hundred diameters out. They are off by default and switched on in the crater albedo's options. The zones fade with the crater, and like it they are left out where the sample spacing cannot resolve the crater.

    options = terraingen.CraterAlbedoOptions(seed=2)
zones = options.zones
zones.enabled = True
options.zones = zones
albedo = terraingen.Albedo(
    terraingen.SyntheticAlbedo(value=0.11), [terraingen.CraterAlbedo(crater, options)]
)
grid = terraingen.RasterGrid.centered((0.0, 0.0), (4000.0, 4000.0), PIXEL)  # meters
(bands,) = terraingen.evaluate_albedo(albedo, grid)

    CraterAlbedoOptions options;
options.seed = 2;
options.zones.enabled = true;
Albedo albedo;
albedo.source = std::make_shared<SyntheticAlbedo>(SyntheticAlbedoOptions{});
albedo.layers = {std::make_shared<CraterAlbedo>(crater, options)};
const RasterGrid grid = RasterGrid::Centered({0.0, 0.0}, {4000.0, 4000.0}, 5.0);  // meters
const std::vector<Raster<float>> bands = EvaluateAlbedo(albedo, grid, {});

    Brighten the Blast Zone Around a Lander¶

    A lander's descent engine scours the regolith around it, leaving a zone brighter than the undisturbed ground and a fainter halo beyond. BlastZone defaults to the Apollo mean, 28785 square meters about 11 percent brighter on average, and can add a dark core where the exhaust dug in. Blast zones need no heights.

    zone = terraingen.BlastZone(x=0.0, y=0.0, area=28785.0, core_radius=15.0, seed=1)  # meters
blasts = terraingen.BlastZoneAlbedo([zone])
albedo = terraingen.Albedo(terraingen.SyntheticAlbedo(value=0.11), [blasts])
grid = terraingen.RasterGrid.centered((0.0, 0.0), (400.0, 400.0), PIXEL)  # meters
(bands,) = terraingen.evaluate_albedo(albedo, grid)

    BlastZone zone;
zone.x = 0.0;
zone.y = 0.0;
zone.area = 28785.0;     // square meters
zone.coreRadius = 15.0;  // meters
zone.seed = 1;
Albedo albedo;
albedo.source = std::make_shared<SyntheticAlbedo>(SyntheticAlbedoOptions{});
albedo.layers = {std::make_shared<BlastZoneAlbedo>(std::vector<BlastZone>{zone})};
const RasterGrid grid = RasterGrid::Centered({0.0, 0.0}, {400.0, 400.0}, 1.0);  // meters
const std::vector<Raster<float>> bands = EvaluateAlbedo(albedo, grid, {});

    Mix Hapke Photometry From a Material Map¶

    A material map gives each cell its share of soil, sand, dust, bedrock and rock, from bare steep ground, dust patches and the layers that lay a material, here dune sand. Each class has Hapke parameters, such as Pancam's fits for Mars at 753 nm, and EvaluatePhotometry mixes them by the shares into rasters of the single-scattering albedo, the two phase function terms and the roughness for a renderer.

    options = terraingen.MaterialOptions(dust_cover=0.3, dust_patch=40.0, seed=1)
materials = terraingen.evaluate_materials(terrain, options, grid)  # soil, sand, dust, bedrock, rock
photometry = terraingen.mars_pancam_photometry()  # Hapke parameters per material at 753 nm
albedo, b, c, roughness = terraingen.evaluate_photometry(materials, photometry)

    MaterialOptions options;
options.dustCover = 0.3;
options.dustPatch = 40.0;  // meters
options.seed = 1;
const std::vector<Raster<float>> materials = EvaluateMaterials(terrain, options, grid);
const MaterialPhotometry photometry = MarsPancamPhotometry();  // per material at 753 nm
// Single-scattering albedo, b, c and roughness.
const std::vector<Raster<float>> hapke = EvaluatePhotometry(materials, photometry);
