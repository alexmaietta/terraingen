    Craters¶

    Add Craters to a Terrain¶

    A crater layer with the default models draws craters from the lunar production function, degraded by their ages, into the heights beneath it. Here it lies on a flat 257 x 257 source of 1 m cells.

    craters = terraingen.CraterLayer()
terrain = terraingen.Terrain(source=terraingen.FlatSource(257, 257, 1.0), layers=[craters])
heights = terrain.evaluate()  # a Raster in meters; .values is a NumPy array

    const auto source = std::make_shared<FlatSource>(257, 257, 1.0);
const Terrain terrain(Surface{}, source, {std::make_shared<CraterLayer>()});
const Raster<float> heights = terrain.Evaluate();  // meters

    List the Craters of a Layer Over a Region¶

    A crater layer on its own lists the craters it places over a region, as centers, diameters, ages and IDs, with no terrain around it. The same seed and region always give the same craters.

    options = terraingen.CraterLayerOptions(
    seed=7, generation=terraingen.CraterGenerationOptions(min_diameter=4.0, max_diameter=120.0)
)
craters = terraingen.CraterLayer(options=options)
table = craters.craters((-200.0, -200.0, 200.0, 200.0))  # min_x, min_y, max_x, max_y in meters
largest = table["diameter"].max()

    CraterLayerOptions options;
options.seed = 7;
options.generation.minDiameter = 4.0;
options.generation.maxDiameter = 120.0;
const CraterLayer craters(DefaultCraterModels(), options);
const CraterList list = craters.Craters({-200.0, -200.0, 200.0, 200.0});  // meters
const double largest = *std::max_element(list.Diameters().begin(), list.Diameters().end());

    List the Craters of a Configuration Without Evaluating Heights¶

    Craters are a pure function of position, so a terrain's crater layers list the craters they would apply over any grid without computing a height. Each comes with its age, floor depth, rim height and freshness. On a body the grid is in degrees of longitude and latitude.

    terrain = terraingen.build_terrain(config)
site = terraingen.RasterGrid.centered((30.0, -10.0), (0.004, 0.004), 0.0001)  # degrees
placed = terrain.craters(site)
table = placed.table  # NumPy columns x, y, diameter, age_gyr, rim_height, ...
placed.write_list(output_folder / "craters.csv")

    const Terrain terrain = BuildTerrain(config);
const RasterGrid site = RasterGrid::Centered({30.0, -10.0}, {0.004, 0.004}, 0.0001);
const CraterFeatures placed = terrain.Craters(site);
const std::vector<double>& diameters = placed.craters.Diameters();  // meters
WriteCraterList(placed.craters, path, ListFormat::Csv, placed.attributes);

    Place Craters by Hand¶

    A manual crater layer holds only the craters you list, such as a catalog of a landing site, and generates none. Each crater takes its depth and rim from the layer's models unless you give its rim-to-floor depth in meters. Listing the layer's craters gives each one's floor depth, rim height and depth ratio as applied, without evaluating any heights.

    craters = terraingen.CraterLayer.manual(
    [
        terraingen.Crater(-30.0, 0.0, 20.0),  # depth and rim from the models
        terraingen.Crater(0.0, 0.0, 20.0, depth=3.0),  # rim to floor, in meters
        terraingen.Crater(30.0, 0.0, 20.0, depth=1.2),
    ]
)
table = craters.craters(REGION)  # each crater's floor_depth, rim_height and depth_ratio

    Crater deep = ManualCrater(0.0, 0.0, 20.0);
deep.depth = 3.0;  // rim to floor, in meters
Crater shallow = ManualCrater(30.0, 0.0, 20.0);
shallow.depth = 1.2;
const auto craters = CraterLayer::Manual({ManualCrater(-30.0, 0.0, 20.0), deep, shallow});
const CraterList list = craters->Craters({-50.0, -20.0, 50.0, 20.0});
const CraterAttributes applied = craters->Models().Shape().Attributes(list.At(1));

    Use Published Crater Models¶

    A crater layer is made of its models, which set how many craters there are of each size, how old they are, how they degrade and the shape of a fresh one. Here they describe a 3.5 Gyr lunar mare with the extended Neukum production function capped by Trask's equilibrium, steady-state ages on Neukum's chronology, degradation by freshness, and Fassett and Thomson's profile.

    surface = terraingen.EquilibriumSurface(
    terraingen.extended_neukum_production_function(),
    terraingen.trask_equilibrium(),
    3.5,
    terraingen.neukum_lunar_chronology,
)
ages = surface.ages()
models = terraingen.CraterModels(
    surface.density(),
    ages,
    terraingen.FreshnessDegradation(ages, terraingen.lunar_fresh_crater_morphometry),
    terraingen.FassettThomsonProfile(),
)
options = terraingen.CraterLayerOptions(
    seed=7, generation=terraingen.CraterGenerationOptions(min_diameter=4.0, max_diameter=120.0)
)
craters = terraingen.CraterLayer(models, options)

    const EquilibriumSurface surface{
    std::make_shared<SplicedSfd>(ExtendedNeukumProductionFunction()),
    std::make_shared<PowerLawSfd>(TraskEquilibrium()), 3.5, NeukumLunarChronology};
const auto ages = surface.Ages();
const CraterModels models{
    surface.Density(), ages,
    std::make_shared<FreshnessDegradation>(ages, LunarFreshCraterMorphometry),
    std::make_shared<FassettThomsonProfile>()};
CraterLayerOptions options;
options.seed = 7;
options.generation.minDiameter = 4.0;
options.generation.maxDiameter = 120.0;
const auto craters = std::make_shared<CraterLayer>(models, options);

    Choose a Crater Profile¶

    A crater profile gives a crater's height by distance from its center for its depth and rim. Martin, Parkes and Dunstan's polynomials give a round bowl, while Fassett and Thomson's fits give straight walls and a flat floor, with a choice of rims. Any of them is the last of a layer's models, and each can be read directly for a crater state.

    profiles = {
    "Martin, Parkes and Dunstan": terraingen.MartinParkesDunstanProfile(),
    "Fassett and Thomson": terraingen.FassettThomsonProfile(),
    "Fassett and Thomson, plateau": terraingen.FassettThomsonProfile(
        terraingen.FassettThomsonRim.PLATEAU
    ),
}
fresh = terraingen.lunar_fresh_crater_morphometry(DIAMETER)
state = terraingen.CraterState(fresh, fresh)  # fresh and current shape alike
heights = {
    name: [profile.height(r * 0.5 * DIAMETER, DIAMETER, state) for r in RADII]
    for name, profile in profiles.items()
}

    const std::map<std::string, std::shared_ptr<const CraterProfile>> profiles{
    {"Martin, Parkes and Dunstan", std::make_shared<MartinParkesDunstanProfile>()},
    {"Fassett and Thomson", std::make_shared<FassettThomsonProfile>()},
    {"Fassett and Thomson, plateau",
     std::make_shared<FassettThomsonProfile>(FassettThomsonRim::Plateau)},
};
const CraterMorphometry fresh = LunarFreshCraterMorphometry(diameter);
const CraterState state{fresh, fresh};  // fresh and current shape alike
std::map<std::string, std::vector<double>> heights;
for (const auto& [name, profile] : profiles) {
    for (int step = 0; step <= 200; ++step) {
        heights[name].push_back(profile->Height(0.01 * step * 0.5 * diameter, diameter, state));
    }
}

    Degrade Craters With Age by Freshness or by Diffusion¶

    A crater layer's degradation model wears each crater by its age. Freshness degradation scales a crater's depth and rim down linearly over its lifetime, while diffusion degradation wears it as topographic diffusion would, quickly at first and then slowly, rounding the rim before the bowl. The depth ratio each one gives a crater can be read without evaluating any heights.

    fresh = terraingen.lunar_fresh_crater_morphometry
ages = terraingen.FreshnessAges(terraingen.ValueDistribution.constant(1.0), 3.0)  # 3 Gyr lifetime
by_freshness = terraingen.CraterModels(None, ages, terraingen.FreshnessDegradation(ages, fresh))
diffusivity = terraingen.PowerLawDiffusivity(coefficient=1.0, exponent=0.0)  # m^2/Myr
profile = terraingen.DiffusedProfile(terraingen.MartinParkesDunstanProfile())
by_diffusion = terraingen.CraterModels(
    None, terraingen.FreshAges(), terraingen.DiffusionDegradation(fresh, diffusivity, profile)
)
worn = {
    name: terraingen.CraterLayer.manual(placed, models).craters(REGION)["depth_ratio"]
    for name, models in (("freshness", by_freshness), ("diffusion", by_diffusion))
}

    const auto ages = std::make_shared<FreshnessAges>(ValueDistribution::Constant(1.0), 3.0);
CraterModels byFreshness;
byFreshness.ages = ages;
byFreshness.degradation =
    std::make_shared<FreshnessDegradation>(ages, LunarFreshCraterMorphometry);
byFreshness.profile = std::make_shared<MartinParkesDunstanProfile>();
PowerLawDiffusivity diffusivity;
diffusivity.coefficient = 1.0;  // m^2/Myr
diffusivity.exponent = 0.0;
const auto profile =
    std::make_shared<DiffusedProfile>(std::make_shared<MartinParkesDunstanProfile>());
CraterModels byDiffusion;
byDiffusion.ages = std::make_shared<FreshAges>();
byDiffusion.degradation =
    std::make_shared<DiffusionDegradation>(LunarFreshCraterMorphometry, diffusivity, profile);
byDiffusion.profile = profile;
const double freshnessRatio = byFreshness.Shape().Attributes(crater).depthRatio;
const double diffusionRatio = byDiffusion.Shape().Attributes(crater).depthRatio;

    Space Craters Apart¶

    Generated craters land at random and may overlap freely. Spacing keeps craters of similar size apart, dropping the lesser of two whose diameters differ by at most the ratio and whose centers lie closer than the separation in larger diameters. It leaves an evenly spread field, as on a surface where new craters have erased old ones.

    generation = terraingen.CraterGenerationOptions(min_diameter=5.0, max_diameter=60.0)
generation.spacing = terraingen.CraterSpacing(diameter_ratio=2.0, separation=1.0)
options = terraingen.CraterLayerOptions(seed=4, generation=generation)
spaced = terraingen.CraterLayer(models, options).craters(REGION)

    CraterLayerOptions options;
options.seed = 4;
options.generation.minDiameter = 5.0;
options.generation.maxDiameter = 60.0;
options.generation.spacing.diameterRatio = 2.0;
options.generation.spacing.separation = 1.0;  // in larger diameters
const CraterList spaced = CraterLayer(models, options).Craters(region);

    Vary Crater Density With a Map¶

    A density map sets a crater layer's density point by point, such as from a crater count map of a site. A scale map multiplies the layer's own density, while count and areal fraction maps measure craters in a diameter range. Here a map rising from 0.1 times in the west to 3 times in the east crowds the craters eastward.

    density_map = terraingen.DensityMap()
density_map.field = terraingen.RasterField(terraingen.Raster.from_array(scale, transform))
density_map.measure = terraingen.DensityMeasure.SCALE  # times the layer's own density
options = terraingen.CraterLayerOptions(
    seed=5, generation=terraingen.CraterGenerationOptions(min_diameter=4.0, max_diameter=60.0)
)
options.density_map = density_map
craters = terraingen.CraterLayer(options=options)
table = craters.craters(REGION)

    DensityMap densityMap;
densityMap.field = std::make_shared<RasterField>(scale);
densityMap.measure = DensityMeasure::Scale;  // times the layer's own density
CraterLayerOptions options;
options.seed = 5;
options.generation.minDiameter = 4.0;
options.generation.maxDiameter = 60.0;
options.densityMap = densityMap;
const CraterLayer craters(DefaultCraterModels(), options);
const CraterList list = craters.Craters({-200.0, -200.0, 200.0, 200.0});

    Roughen and Stretch Crater Rims¶

    Irregularity in the apply options roughens crater rims with random harmonics and stretches a share of craters into ellipses, as low-angle impacts make them. Each crater draws its outline from its ID, so the outline a crater gets can be read without evaluating any heights. Manual craters stay round unless the selection includes them.

    irregularity = terraingen.CraterIrregularity(
    enabled=True,
    seed=3,
    selection=terraingen.CraterSelection(manual=True),  # manual craters stay round otherwise
    roughness=terraingen.ValueDistribution.constant(0.06),  # RMS deviation, in radii
    elongated_share=0.5,
    ellipticity=terraingen.ValueDistribution.uniform(1.2, 1.6),  # long over short axis
)
apply = terraingen.CraterApplyOptions(irregularity=irregularity)
craters = terraingen.CraterLayer.manual(placed, apply=apply)

    CraterIrregularity irregularity;
irregularity.enabled = true;
irregularity.seed = 3;
irregularity.selection.manual = true;  // manual craters stay round otherwise
irregularity.roughness = ValueDistribution::Constant(0.06);  // RMS deviation, in radii
irregularity.elongatedShare = 0.5;
irregularity.ellipticity = ValueDistribution::Uniform(1.2, 1.6);  // long over short axis
CraterApplyOptions apply;
apply.irregularity = irregularity;
const auto craters = CraterLayer::Manual(placed, DefaultCraterModels(), apply);

    Raise Central Peaks in Complex Craters¶

    A complex crater profile gives craters above the simple to complex transition, 15 km on the Moon, a flat floor and a round central dome. Peaks in the apply options raise that dome into a cluster of massifs drawn per crater from its ID, sized by the profile's peak height and base.

    models = terraingen.CraterModels(
    None,
    terraingen.FreshAges(),
    terraingen.NoDegradation(terraingen.lunar_fresh_crater_morphometry),
    terraingen.ComplexCraterProfile(
        terraingen.MartinParkesDunstanProfile(), terraingen.lunar_complex_crater_shape()
    ),
)
apply = terraingen.CraterApplyOptions()
apply.peaks = terraingen.CraterPeaks(enabled=True, min_massifs=2, max_massifs=5)
craters = terraingen.CraterLayer.manual([terraingen.Crater(0.0, 0.0, 40000.0)], models, apply=apply)
terrain = terraingen.Terrain(source=terraingen.FlatSource(SIZE, SIZE, PIXEL), layers=[craters])
heights = terrain.evaluate()

    CraterModels models;
models.ages = std::make_shared<FreshAges>();
models.degradation = std::make_shared<NoDegradation>(LunarFreshCraterMorphometry);
models.profile = std::make_shared<ComplexCraterProfile>(
    std::make_shared<MartinParkesDunstanProfile>(), LunarComplexCraterShape());
CraterApplyOptions apply;
apply.peaks.enabled = true;
apply.peaks.minMassifs = 2;
apply.peaks.maxMassifs = 5;
const auto craters = CraterLayer::Manual({ManualCrater(0.0, 0.0, 40000.0)}, models, apply);
const Terrain terrain(Surface{}, std::make_shared<FlatSource>(201, 201, 300.0), {craters});
const Raster<float> heights = terrain.Evaluate();

    Terrace the Walls of Large Craters¶

    Terraces in the apply options slump the walls of large complex craters into benches and scarps. They begin at the onset diameter with one bench over part of the wall and grow to the most benches around most of it, each crater drawing its own from its ID.

    apply = terraingen.CraterApplyOptions()
apply.terraces = terraingen.CraterTerraces(enabled=True, onset_diameter=20000.0, max_benches=4)
craters = terraingen.CraterLayer.manual([terraingen.Crater(0.0, 0.0, 60000.0)], models, apply=apply)
terrain = terraingen.Terrain(source=terraingen.FlatSource(SIZE, SIZE, PIXEL), layers=[craters])
heights = terrain.evaluate()

    CraterApplyOptions apply;
apply.terraces.enabled = true;
apply.terraces.onsetDiameter = 20000.0;  // meters
apply.terraces.maxBenches = 4;
const auto craters = CraterLayer::Manual({ManualCrater(0.0, 0.0, 60000.0)}, models, apply);
Terrain terrain(Surface{}, std::make_shared<FlatSource>(221, 221, 400.0), {craters});
const Raster<float> heights = terrain.Evaluate();

    Throw Secondary Craters in Rays¶

    A secondary crater layer scatters the craters a primary layer's craters throw, from their onset range out to about 1.6 times the median ray length, sized after Singer et al. With rays on, a share of them gather into ray chains and clusters. Listing them needs no heights; add both layers to a terrain to draw them.

    primary = terraingen.CraterLayer.manual([terraingen.Crater(0.0, 0.0, PRIMARY_DIAMETER)])
options = terraingen.SecondaryCraterOptions(seed=3, onset_count=1000.0, min_diameter=24.0)
options.rays = terraingen.SecondaryRays(enabled=True, share=0.7)  # 70% of them gather in rays
secondaries = terraingen.SecondaryCraterLayer(primary, options)
region = (-HALF_SIZE_M, -HALF_SIZE_M, HALF_SIZE_M, HALF_SIZE_M)
table = secondaries.secondaries(region)  # add both layers to a terrain to draw them

    const auto primary = CraterLayer::Manual({ManualCrater(0.0, 0.0, 2000.0)});
SecondaryCraterOptions options;
options.seed = 3;
options.onsetCount = 1000.0;
options.minDiameter = 24.0;  // meters
options.rays.enabled = true;
options.rays.share = 0.7;  // 70% of them gather in rays
const SecondaryCraterLayer secondaries(primary, options);
const CraterList list = secondaries.Secondaries({-11000.0, -11000.0, 11000.0, 11000.0});

    Skip the Craters a DEM Already Resolves¶

    A DEM already holds the craters large enough for its posts to resolve, so a crater layer on it should add only the smaller ones. Given the DEM as its source, a layer drops generated craters at least the source resolves pixels of its cells across, 4 by default. Here a DEM with 8 m posts gets only craters under 32 m.

    options = terraingen.CraterLayerOptions(
    seed=5, generation=terraingen.CraterGenerationOptions(min_diameter=4.0, max_diameter=200.0)
)
options.source_resolves_px = resolves_pixels  # DEM cells across; None keeps every crater
base = terraingen.TerrainBase(terraingen.Surface.plane(), dem)
craters = terraingen.CraterLayer(options=options, base=base)
table = craters.craters(REGION)  # only craters under 4 x 8 m = 32 m across

    CraterLayerOptions options;
options.seed = 5;
options.generation.minDiameter = 4.0;
options.generation.maxDiameter = 200.0;
options.sourceResolvesPixels = 4.0;  // DEM cells across; unset keeps every crater
const CraterLayer craters(DefaultCraterModels(), options, TerrainBase{Surface::Plane(), dem});
const CraterList list = craters.Craters({-300.0, -300.0, 300.0, 300.0});

    Replace a Crater a DEM Holds Blurred¶

    A DEM's posts soften the craters it holds: rims round off and bowls fill in between posts. A manual crater with replace set swaps whatever the terrain holds there for a sharp crater of its diameter and depth, cut into a plane fitted on a ring just beyond its reach, so neither the old bowl nor its rim pulls the new crater down. Here a DEM with 4 m posts holds a 40 m crater only 2 m deep, and a replacing crater makes it 8 m deep.

    sharp = terraingen.Crater(0.0, 0.0, 40.0, depth=8.0, replace=replace)  # swaps out what is there
base = terraingen.TerrainBase(terraingen.Surface.plane(), dem)
craters = terraingen.CraterLayer.manual([sharp], base=base)
terrain = terraingen.Terrain(source=dem, layers=[craters])
heights = terrain.evaluate(WINDOW).values  # 0.5 m over the crater

    Crater sharp = ManualCrater(0.0, 0.0, 40.0);
sharp.depth = 8.0;
sharp.replace = true;  // swaps out what the DEM holds there
const auto craters = CraterLayer::Manual({sharp}, DefaultCraterModels(), DefaultCraterApply(),
                                         TerrainBase{Surface::Plane(), dem});
const Terrain terrain(Surface::Plane(), dem, {craters});
const Raster<float> heights =
    terrain.Evaluate(RasterGrid::Centered({0.0, 0.0}, {100.0, 100.0}, 0.5));

    Restamp Craters from a Coarser Run¶

    Running a terrain coarse first and then finer on its heights blurs the coarse run's craters: the finer run upsamples them between posts. Inherited craters read from the coarse run's crater list are stamped again sharp, with their IDs, ages and realized depths, where the source resolves them, replacing what it holds; generated craters fill the gaps beneath, so none is drawn twice. Here a run at 8 m hands its craters from 32 m across to a run at 1 m.

    inherited = terraingen.InheritedCraters(
    craters=terraingen.read_crater_list(output_folder / "coarse_craters.json"),
    max_source_px=None,  # restamp every crater the DEM resolves, however large
)
craters = crater_layer(base, inherited if restamp else None)  # the coarse run's layer, on its heights
heights = terraingen.Terrain(source=dem, layers=[craters]).evaluate(WINDOW).values

    InheritedCraters inherited;
inherited.craters = ReadCraterList(list);  // with the coarse run's realized depths
const auto craters = Craters(inherited, TerrainBase{Surface::Plane(), dem});
const Terrain fine(Surface::Plane(), dem, {craters});
const Raster<float> heights =
    fine.Evaluate(RasterGrid::Centered({0.0, 0.0}, {200.0, 200.0}, 1.0));
