    Detailed Description¶

    Row 0 is the first row in the file, the northern edge for north-up rasters. Cells are addressed as (column, row), matching the (x, y) order of GeoTransform. A copy always owns its cells; a move keeps borrowing what the raster borrowed.

    Template parameters:

    • T Cell type, usually float heights in meters.
