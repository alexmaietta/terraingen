    boulders¶

    Boulders scattered over the ground from a size distribution, in patches and around fresh craters, as relief or 3D models.

    generate_random

    boolean · default true

    Draws random boulders from the size distribution, between craters and around them; off places only the manual boulders, and the sizes, coverage and ejecta go unused.

    coverage

    number, optional · default null

    Golombek-Rapp k, the fraction of the ground covered by boulders, above 0 when generating random boulders; higher values give more boulders. Unset is 0.02. Only golombek_rapp sizes use it, so set it only with them. Must be from 0 to below 1.

    qa

    number, optional · default null · unit 1/m

    Constant term of the Golombek-Rapp q = qa + qb / k, per meter; a larger q leaves fewer large boulders. Unset is 1.79. Only golombek_rapp sizes or ejecta sizes use it, so set it only with them.

    qb

    number, optional · default null · unit 1/m

    Term of the Golombek-Rapp q = qa + qb / k divided by the coverage k, per meter; unset is 0.152, and it is used as qa is.

    min_diameter_m

    number · default 0.1 · unit m

    Smallest boulder generated, in meters; lower values add many more small boulders. Must be positive.

    max_diameter_m

    number · default 5.861381645140288 · unit m

    Largest boulder generated, in meters, exclusive; above the smallest. Must be positive.

    sizes

    boulder sizes · default {"type": "sp8023_intercrater", ...}

    Size distribution of the boulders between craters, per m^2; patches and bedrock scale its density.

    seed

    integer · default 1

    Seed of the boulders, their attributes and the patches; changing it gives a different boulder field of the same statistics.

    ejecta_sizes

    boulder sizes, optional · default null

    Size distribution of the blocks at the rim of a fresh crater, per m^2; golombek_rapp uses the ejecta's coverage with qa and qb. Unset follows sizes.

    extrapolate

    boolean · default false

    Lets the size distributions be evaluated outside their valid diameters, such as beyond a table's published ones; otherwise they must cover the boulder sizes.

    bedrock_abundance

    number · default 3.0

    Boulder abundance on bedrock over that on soil, and in between in proportion; used with the exposure field. Must be positive.

    bedrock_mean_size_m

    number · default 1000.0 · unit m

    With a density map, the side in meters of the squares bedrock is held to the map's mean over, so it gathers boulders without adding any; a GeoTIFF map uses its own cells. Must be positive.

    min_height_ratio

    number · default 0.4

    Smallest boulder height over diameter; each boulder's is drawn uniformly between the two ratios. Must be positive.

    max_height_ratio

    number · default 0.6

    Largest boulder height over diameter; at least the smallest. Must be positive.

    min_burial

    number · default 0.1

    Smallest buried share of a boulder's height; each boulder's is drawn uniformly between the two shares. Must be from 0 to below 1.

    max_burial

    number · default 0.4

    Largest buried share of a boulder's height; more burial leaves less of the boulder exposed. Must be from 0 to below 1.

    max_lean_deg

    number · default 14.896902673401405 · unit deg

    Largest tilt of a boulder from the vertical, in degrees. Must not be negative.

    side_share

    number · default 0.0

    Share of boulders resting on a side, their intermediate axis up, rather than on their broadest face. Must be from 0 to 1.

    end_share

    number · default 0.0

    Share of boulders standing on an end, their long axis up; with side_share, at most 1. Must be from 0 to 1.

    max_tilt_deg

    number · default 0.0 · unit deg

    Largest tilt of a boulder's up axis from the vertical in a random direction, after its lean, in degrees; tilts are spread evenly over that cap of directions. Must be from 0 to 180 deg.

    follow_slope

    boolean · default false

    Settles each boulder on the slope of the ground beneath it before its tilt.

    settle

    boolean · default true

    Tips each boulder model over until it rests stably on a face, its center of mass over what it stands on, rather than balanced on an edge or corner.

    max_slope_deg

    number, optional · default null · unit deg

    Steepest ground, across a boulder's diameter, that boulders stay on, in degrees; steeper ground has none, models and drawn boulders alike. Unset keeps boulders on any slope. Must be above 0 and below 90 deg.

    roll_distance_m

    number, optional · default null · unit m

    With max_slope_deg, boulders on steeper ground roll down it and rest where it is gentle enough, gathering at the foot of slopes; those that would roll farther than this many meters are left out. Unset leaves out every boulder on steeper ground. Must be positive.

    burial_by_wear

    number · default 0.0

    How far wear sets burial: blocks of fresh craters sit near the smallest burial and those of worn ones sink toward the largest, while boulders between craters span every stage; 0 draws burial uniformly. Must be from 0 to 1.

    relief

    one of dome, shape, none · default "dome"

    How the boulders drawn into the heights look there.

    shape_files

    list of string · default []

    Rock meshes (.obj with its .mtl, .gltf or .glb) the boulder shapes are drawn from instead of the procedural styles, each boulder picking one by its shape seed; paths relative to the configuration. Empty keeps the procedural shapes.

    shape_prototypes

    integer · default 64

    How many shapes the boulders share, so they can be drawn as instances; 0 gives every boulder a shape of its own.

    ground_spacing_m

    number · default 1.0 · unit m

    Spacing in meters at which the layer reads the ground beneath it, for the exposure field, placement, settling, slopes and breaking; fixed so that which boulders exist does not depend on the level of detail. Must be positive.

    fade_px

    list of number · default [...] · unit px

    Which boulders are drawn into the heightmap by their size in output samples (pixels): the first count is the smallest drawn (2 by default, the fewest that resolve a boulder) and the second the size from which they are drawn in full. Smaller boulders exist only in the boulder lists and 3D models. Each must not be negative.

    fade_shape

    one of linear, smoothstep, smootherstep, gaussian · default "smoothstep"

    Curve of the fade between the two sample counts of fade_px.

    source_resolves_px

    number, optional · default null · unit px

    Source cells across from which the source's data already holds the boulders (the smaller of this and completeness when both are set), by their diameter: only smaller ones are added, each raster of a chain giving its own limit. Ignored on synthetic sources and where no raster has data; null adds them all. Must be positive.

    patches: Patches of richer and poorer boulder cover across the ground.
    spread

    number · default 1.0

    Boulder abundance varies from 1 / spread to spread times its mean; 1 is the same everywhere. Must be at least 1.

    size_m

    number · default 200.0 · unit m

    Typical width of a patch of richer or poorer boulder cover, in meters. Must be positive.

    clusters: Clusters of the boulders between craters around scattered centers; off unless share is set.
    share

    number · default 0.0

    Share of the boulders between craters gathered in clusters; 0 leaves them scattered. Must be from 0 to 1.

    center_spacing_m

    number · default 50.0 · unit m

    Typical distance between cluster centers, in meters; with thomas, one center per spacing squared on average. Must be positive.

    radius_m

    number · default 5.0 · unit m

    Gaussian radius of a cluster, in meters; below the spacing with nearest, at most twice it with thomas. Must be positive.

    model

    one of nearest, thomas · default "nearest"

    How cluster centers are laid out and their clusters combine.

    ejecta: Blocks thrown out by craters of every top-level crater layer before this one that dug into boulder, densest at the rim and thinning outward; none with generate_random off.
    min_crater_diameter_m

    number, optional · default null · unit m

    Smallest crater, in meters, that throws blocks out; unset with no regolith thickness, no crater throws blocks. Must not be negative.

    regolith_thickness_m

    number, optional · default null · unit m

    Regolith thickness in meters: craters smaller than it over the excavation depth ratio dig no boulder and throw no blocks. Unset ignores the regolith. Must be positive.

    excavation_depth_ratio

    number · default 0.1

    Depth of excavation over crater diameter; with the regolith thickness it sets the smallest crater that throws blocks. Must be above 0 and at most 1.

    coverage

    number, optional · default null

    Golombek-Rapp k, the fraction of ground covered by blocks at the rim of a fresh crater; unset is 0.1. Only golombek_rapp ejecta sizes use it, so set it only with them. Must be above 0 and below 1.

    profile

    one of smoothstep, exponential · default "smoothstep"

    How the share of a crater's blocks falls off with distance from its center.

    reach

    number · default 3.0

    Distance from the crater's center, in crater radii, beyond which it adds no blocks. Must be above 1.

    decay_radii

    number · default 0.7

    With the exponential profile, the e-folding distance of the blocks outside the rim, in crater radii. Must be positive.

    floor_share

    number · default 0.05

    With the exponential profile, the crater floor's share of the rim's blocks. Must be from 0 to 1.

    aging

    one of freshness, age · default "freshness"

    How a crater's blocks wear away with time, so that few are left around old craters.

    min_freshness

    number · default 0.7

    With freshness aging, the freshness (current over fresh depth) at or below which a crater keeps no blocks. Must be from 0 to below 1.

    lifetime_gyr

    number · default 4.0 · unit Gyr

    With age aging, the crater age in Gyr at which a crater keeps no blocks. Must be positive.

    aging_exponent

    number · default 3.0

    With age aging, the exponent of (1 - age / lifetime); higher values strip blocks from craters sooner. Must not be negative.

    gravity

    number, optional · default null

    Surface gravity in m/s^2: with the regolith thickness, it limits how far blocks are thrown, after Bart and Melosh (2010). Unset applies no such limit. Must be positive.

    exposure: Raises the abundance of boulders where the ground beneath is bedrock, judged from its shape; unset disables it.
    reach_m

    number · default 12.0 · unit m

    Distance in meters around a point at which its surroundings are read, to tell rises from lows. Must be positive.

    rise_soil

    number · default 0.01

    Height above the surroundings, as a share of the reach, at or below which the ground is soil.

    rise_boulder

    number · default 0.035

    Height above the surroundings, as a share of the reach, at or above which the ground is bedrock; above the soil threshold.

    slope_soil

    number · default 0.2

    Slope, as rise over run, at or under which soil holds.

    slope_boulder

    number · default 0.4

    Slope, as rise over run, at or over which no soil holds and the ground is bedrock; above the soil threshold.

    floor_cover

    number · default 0.0

    Share of level ground that is bedrock too, in noise patches, as on a swept lava floor; 0 for none. Must be from 0 to below 1.

    floor_patch_m

    number · default 60.0 · unit m

    Width of the bedrock patches on level ground, in meters. Must be positive.

    seed

    integer · default 0

    Seed of the bedrock patches on level ground.

    fillet: Regolith piled against each boulder's base, around relief and models alike; off unless height_share is set.
    height_share

    number · default 0.0

    Height of the regolith piled against a boulder, as a share of its exposed height; 0 draws no fillets. Must be from 0 to 1.

    width_ratio

    number · default 0.3

    How far the fillet reaches beyond the boulder's edge, over its diameter; it falls to nothing there. Must be positive.

    ventifacts: Windward facets planed on boulders by sand-laden wind, from wear; off unless share is set.
    share

    number · default 0.0

    Share of boulders with a windward facet planed by sand-laden wind; 0 for none. Gale crater: 0.39 (Bridges et al. 2014). Must be from 0 to 1.

    wind_azimuth_deg

    number · default 0.0 · unit deg

    Direction the abrading wind blows toward, in degrees counter-clockwise from +x (local east on a body); facets face the other way.

    min_angle_deg

    number · default 50.0 · unit deg

    Gentlest facet slope from horizontal, in degrees; 50 to 60 on basalt (Laity and Bridges 2009). Must be above 0 and below 90 deg.

    max_angle_deg

    number · default 60.0 · unit deg

    Steepest facet slope from horizontal, in degrees. Must be above 0 and below 90 deg.

    second_wind_azimuth_deg

    number, optional · default null · unit deg

    A second abrading wind, where it blows toward, in degrees like the first; some faceted boulders get a second facet facing it and a keel between. Unset for none.

    keel_share

    number · default 0.0

    Share of faceted boulders with the second facet. Gale crater: 12 of 39 (Bridges et al. 2014). Must be from 0 to 1.

    fragmentation: Boulders broken by wear into pieces that replace them, split and then scattered as rubble; leave it out for none to break.
    min_diameter_m

    number · default 1.0 · unit m

    Smallest boulder that breaks, in meters. Must be positive.

    split_wear

    number · default 0.5

    Wear from 0 (fresh) to 1 from which boulders split into pieces that still fit; 0.5 by default. Must be from 0 to 1.

    rubble_wear

    number · default 1.0

    Wear from which the pieces scatter as rubble, turn and sink; at least split_wear. Must be from 0 to 1.

    min_pieces

    integer · default 2

    Fewest pieces a boulder breaks into. Must be from 2 to 12.

    max_pieces

    integer · default 5

    Most pieces a boulder breaks into. Must be from 2 to 12.

    gap_ratio

    number · default 0.04

    Widest crack between split pieces, as a share of the boulder's diameter. Must not be negative.

    spread_ratio

    number · default 0.6

    How far rubble scatters beyond the cracks, as a share of the boulder's diameter. Must not be negative.

    slab_share

    number · default 0.7

    Share of broken boulders split by roughly parallel cracks right through them; the rest crack out from the middle. Must be from 0 to 1.

    model_threshold: Which boulders become 3D models of their own rather than relief in the heights; neither threshold set means no models.
    min_diameter_m

    number, optional · default null · unit m

    Boulders at least this many meters across become 3D models; unset applies no diameter threshold. Must be positive.

    min_px

    number, optional · default null · unit px

    Boulders spanning at least this many samples at the spacing evaluated become 3D models, so finer levels of detail make more of them; unset applies no such threshold. Must be positive.

    max_diameter_m

    number, optional · default null · unit m

    Boulders this many meters across or wider are not models, keeping a band of sizes as models; unset applies no upper limit. Must be positive.

    max_px

    number, optional · default null · unit px

    Boulders spanning this many samples or more are not models; unset applies no such limit. Must be positive.

    relief_range: Which boulders are drawn into the heights by diameter: none below min_diameter_m or from max_diameter_m, and models only when asked.
    min_diameter_m

    number · default 0.0 · unit m

    Smallest boulder drawn into the heights, in meters; smaller ones stay in the lists only, for the renderer's surface detail. Must not be negative.

    max_diameter_m

    number, optional · default null · unit m

    Boulders this many meters across or wider are not drawn into the heights; unset applies no upper limit. Must be positive.

    include_models

    boolean · default false

    Draws the 3D model boulders into the heights as well, as a stand-in for far views.

    shapes: The boulders' 3D boulder shapes, used by shape relief and by models.
    subdivisions

    integer · default 3

    Times the solid's triangles are split in four; more give finer, smoother shapes with more triangles. Must be from 0 to 6.

    weathering

    number · default 1.0

    Scales every style's edge softness: 0 gives sharp edges, 1 the styles' own, more is more worn. Must not be negative.

    seed

    integer · default 0

    Seed the shapes are drawn with, along with each shape's own seed; changing it reshapes every boulder.

    styles[]: Kinds of boulder each shape is drawn from, picked by weight. Holds at least 1 item.
    name

    string · default ""

    Label of the style, for reference; it does not change the shapes.

    weight

    number · default 1.0

    Relative share of boulders given this style; the styles' weights must not all be 0. Must not be negative.

    solid

    one of icosahedron, cube, pyramid, prism, tetrahedron · default "icosahedron"

    Solid the shape starts from, before it is stretched, rounded, roughened and fractured.

    min_fractures

    integer · default 0

    Fewest flat fracture planes cutting a boulder; each boulder's count is drawn between the two. Must be from 0 to 64.

    max_fractures

    integer · default 0

    Most flat fracture planes cutting a boulder; at least the fewest. Must be from 0 to 64.

    max_fracture_tilt

    number · default 1.0

    Largest vertical component of a fracture plane's unit normal: 0 keeps normals horizontal, cutting a slab about its rim only. Must be from 0 to 1.

    noise_amplitude

    number · default 0.05

    Largest relative change of the radius by the roughening noise; 0 leaves the surface unroughened. Must be from 0 to below 1.

    noise_wavelength

    number · default 0.6

    Wavelength of the roughening noise's first octave, in long-axis lengths; smaller values give finer bumps. Must be positive.

    noise_octaves

    integer · default 3

    Octaves of the roughening noise, each halving in wavelength; more add finer detail. Must be from 1 to 12.

    face_roughness

    number · default 0.0

    How far fracture faces undulate, as a share of each plane's offset; 0 keeps them flat. Must be from 0 to 0.5.

    intermediate: Range of the intermediate axis over the long one, b / a, within (0, 1]; lower values give more elongated boulders.
    min

    number · default 0.0

    Lower end of the interval the value is drawn uniformly from.

    max

    number · default 0.0

    Upper end of the interval the value is drawn uniformly from.

    short_axis: Range of the short, vertical axis over the long one, c / a, within (0, 1] and at most the intermediate ratio; lower values give flatter boulders.
    min

    number · default 0.0

    Lower end of the interval the value is drawn uniformly from.

    max

    number · default 0.0

    Upper end of the interval the value is drawn uniformly from.

    rounding: Range of the share, from 0 to 1, by which the shape is rounded toward the ellipsoid of its axes: 0 keeps the solid's edges and corners, 1 is the ellipsoid.
    min

    number · default 0.0

    Lower end of the interval the value is drawn uniformly from.

    max

    number · default 0.0

    Upper end of the interval the value is drawn uniformly from.

    fracture_depth: Range of where each fracture plane lies, as a share of the shape's reach along its normal, within (0, 1]; lower values cut more away.
    min

    number · default 0.0

    Lower end of the interval the value is drawn uniformly from.

    max

    number · default 0.0

    Upper end of the interval the value is drawn uniformly from.

    edge_softness: Range of how far edges and corners are worn back where faces meet, as weathering rounds them, in long-axis lengths from 0 to 0.5; 0 keeps them sharp.
    min

    number · default 0.0

    Lower end of the interval the value is drawn uniformly from.

    max

    number · default 0.0

    Upper end of the interval the value is drawn uniformly from.

    density_map: Map that sets the abundance of boulders between craters point by point, scaling the sizes to what it measures; unset keeps the abundance the sizes set everywhere.
    measure

    one of scale, count, areal_fraction · default "scale"

    What the map's values measure.

    min_diameter_m

    number · default 0.0 · unit m

    Smallest diameter the map measures, in meters; positive for a count or areal fraction. Must not be negative.

    max_diameter_m

    number, optional · default null · unit m

    Largest diameter the map measures, in meters, exclusive; unset for no limit. Must be positive.

    area_unit

    number · default 1.0 · unit m^2

    Square meters per area unit of a count: 1 for per m^2, 1e6 for per km^2. Must be positive.

    total

    boolean · default true

    The map counts every feature of its kind, including the secondaries thrown from a crater layer's craters and the boulders a layer throws out around craters, which are taken out of it first; off when it counts only what the layer generates.

    field: The map.
    path

    string · default ""

    GeoTIFF read in the surface's coordinates, relative to the configuration's folder: meters on a plane, longitude and latitude in degrees on a sphere. Empty uses value.

    value

    number · default 0.0

    The field everywhere when no path is given.

    band

    integer · default 0

    Band of the GeoTIFF read, from 0.

    method

    one of nearest, bilinear, cubic, catmull_rom, lanczos3, cubic_bspline · default "bilinear"

    How the raster is interpolated: nearest or bilinear, which stay within the cells read.

    scale

    number · default 1.0

    Multiplies every cell, such as 0.001 for a map stored in thousandths. Must be positive.

    fallback

    number, optional · default null

    Value outside the raster and where its cells are no-data or NaN; unset leaves none, and the layer then keeps its own setting there.

    periodic_longitude

    boolean · default false

    The raster's x is longitude repeating every 360 degrees, so a map from 0 to 360 serves -180 to 180.

    slope_map: Map of how steeply boulder counts fall with size, such as a mean diameter map, bending the sizes into a local power law through their count at its reference diameter; needs a size distribution. Unset keeps the sizes' shape everywhere.
    measure

    one of exponent, mean_diameter · default "exponent"

    What the map's values measure.

    reference_diameter_m

    number · default 1.0 · unit m

    Diameter D0 in meters where the local power law meets the layer's own count, as N(>=D) = N(>=D0) (D / D0)^-alpha; for a mean diameter map, the smallest diameter averaged. Must be positive.

    min_exponent

    number · default 1.0

    Smallest exponent alpha the map's values are clamped to; with the largest it bounds the boulders drawn, so generous bounds draw more to thin. Must be positive.

    max_exponent

    number · default 6.0

    Largest exponent alpha the map's values are clamped to; above the smallest. Must be positive.

    field: The map.
    path

    string · default ""

    GeoTIFF read in the surface's coordinates, relative to the configuration's folder: meters on a plane, longitude and latitude in degrees on a sphere. Empty uses value.

    value

    number · default 0.0

    The field everywhere when no path is given.

    band

    integer · default 0

    Band of the GeoTIFF read, from 0.

    method

    one of nearest, bilinear, cubic, catmull_rom, lanczos3, cubic_bspline · default "bilinear"

    How the raster is interpolated: nearest or bilinear, which stay within the cells read.

    scale

    number · default 1.0

    Multiplies every cell, such as 0.001 for a map stored in thousandths. Must be positive.

    fallback

    number, optional · default null

    Value outside the raster and where its cells are no-data or NaN; unset leaves none, and the layer then keeps its own setting there.

    periodic_longitude

    boolean · default false

    The raster's x is longitude repeating every 360 degrees, so a map from 0 to 360 serves -180 to 180.

    manual[]: Catalog or hand-placed boulders placed as given and never thinned or left out; fields left unset are drawn as for generated boulders. Boulders fixing any field never break.
    x

    number · default 0.0

    Center along x in the surface's coordinates; the longitude in degrees on a sphere.

    y

    number · default 0.0

    Center along y in the surface's coordinates; the latitude in degrees on a sphere.

    diameter_m

    number · default 0.0 · unit m

    Length of the long axis, in meters. Must be positive.

    id

    integer, optional · default null

    Stable ID that seeds what is drawn for the boulder; unset derives one from its position and diameter.

    height_m

    number, optional · default null · unit m

    Vertical extent in meters, buried part included; unset draws it from the height ratios. Must be positive.

    burial

    number, optional · default null

    Buried share of the height; unset draws it. Must be from 0 to below 1.

    yaw_deg

    number, optional · default null · unit deg

    Rotation about the vertical, degrees counter-clockwise from east; unset draws it.

    lean_deg

    number, optional · default null · unit deg

    Tilt of the boulder's vertical axis from the vertical, degrees; unset draws it.

    tilt_deg

    number, optional · default null · unit deg

    Angle of the up axis from the vertical after lean, degrees; unset draws it. A followed slope tips it further.

    tilt_azimuth_deg

    number, optional · default null · unit deg

    Direction the up axis tips toward, degrees counter-clockwise from east; unset draws it.

    wear

    number, optional · default null

    How worn it is, 0 fresh; unset draws it. With burial_by_wear it sets a drawn burial. Must be from 0 to 1.

    model

    boolean, optional · default null

    Whether it is a 3D model rather than relief in the heights; unset follows the layer's model threshold.

    rest

    one of face, side, end, optional · default null

    Which axis it stands along; unset draws it. A fixed lean, tilt, tilt azimuth or rest keeps a model from being tipped over by settle.

    shape_seed

    integer, optional · default null

    Seed of its 3D shape, as a generated boulder's derived one; unset derives it from the ID.

    completeness: Where the manual boulders are a complete catalog: the diameter in meters from which they stand in for generated boulders, infinite or no value where there is no catalog. Unset keeps every generated boulder.
    path

    string · default ""

    GeoTIFF read in the surface's coordinates, relative to the configuration's folder: meters on a plane, longitude and latitude in degrees on a sphere. Empty uses value.

    value

    number · default 0.0

    The field everywhere when no path is given.

    band

    integer · default 0

    Band of the GeoTIFF read, from 0.

    method

    one of nearest, bilinear, cubic, catmull_rom, lanczos3, cubic_bspline · default "bilinear"

    How the raster is interpolated: nearest or bilinear, which stay within the cells read.

    scale

    number · default 1.0

    Multiplies every cell, such as 0.001 for a map stored in thousandths. Must be positive.

    fallback

    number, optional · default null

    Value outside the raster and where its cells are no-data or NaN; unset leaves none, and the layer then keeps its own setting there.

    periodic_longitude

    boolean · default false

    The raster's x is longitude repeating every 360 degrees, so a map from 0 to 360 serves -180 to 180.
