# Guides

How to use TerrainGen, from its tools to single tasks:

- [Command line](command-line.md): generating terrain from a configuration with the `terraingen` command.
- [GUI](gui.md): viewing and editing a terrain in the `terraingen --gui` app.
- [Contributing](contributing.md): building, testing and changing TerrainGen.

## Tasks

Short Python and C++ examples of single tasks, by topic. Many list craters or boulders, write 3D boulder models or evaluate an albedo straight from a configuration, without evaluating any heights. Each example is built and run as a test, so it keeps working.
