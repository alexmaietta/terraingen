# Guides

These guides show how to use TerrainGen, from its tools to single tasks.

- [Tools](tools/index.md) covers the `terraingen` command line and the GUI.
- [Workflows](workflows/index.md) has detailed walkthroughs and tutorials that take several steps.

## Tasks

Short Python and C++ examples of single tasks, by topic. Many list craters or boulders, write 3D boulder models or evaluate an albedo straight from a configuration, without evaluating any heights. Customization replaces TerrainGen's parts with your own, and [Customize TerrainGen](workflows/customize-terraingen.md) walks through them all. Each example is built and run as a test, so it keeps working, and most show what they make.
