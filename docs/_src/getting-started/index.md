# Getting started

TerrainGen generates planetary terrain from a JSON configuration on the command line, from Python, or from C++. These pages take you from installing it to a first terrain of your own.

1. [Installation](installation.md): install the Python package or a release, or build from source.
2. [Quickstart](quickstart.md): generate an example terrain in a few minutes, from the command line, Python or C++.
3. [Your first terrain](first-terrain.md): build a terrain one layer at a time, from a flat source to craters, boulders and albedo.

After that:

- [Guides](../guides/index.md) show how to do specific tasks, such as using the command line, the GUI or the examples.
- [Concepts](../concepts/index.md) explain how TerrainGen is designed.
- [Features](../features/index.md) describe each model in detail.
- [Reference](../reference/index.md) has the configuration schema, the APIs, the changelog and the bibliography.
