    craters¶

    Impact craters generated from a density and age model, or placed by hand, and cut into the terrain.

    morphometry

    one of lunar, mars · default "lunar"

    Published fits of fresh crater depth, rim height and complex crater shape the craters are shaped with.

    generate_random

    boolean · default true

    Draws random craters from the size distribution; off places only the manual craters.

    seed

    integer · default 1

    Seed the craters are generated with; changing it gives a different crater field of the same statistics.

    density

    crater densities · default {"type": "minimum", ...}

    Size-frequency distribution of the generated craters: how many of each diameter per unit area.

    ages

    crater ages, optional · default null

    How generated craters are given ages, which the degradation model wears them down by; unset gives steady-state ages on the density's production surface and equilibrium.

    min_diameter_m

    number · default 2.5 · unit m

    Smallest crater generated, in meters; lower values add many more small craters. Must be positive.

    max_diameter_m

    number · default 250.0 · unit m

    Largest crater generated, in meters; above the smallest. Must be positive.

    max_craters

    integer, optional · default null

    Most generated craters kept, the largest first; unset keeps all. Manual craters are always kept, and a cap means tiles no longer match the whole grid.

    profile

    crater profiles · default {"type": "martin_parkes_dunstan", ...}

    Shape of a fresh crater's cross-section, scaled to each crater's diameter.

    degradation

    crater degradation · default {"type": "diffusion", ...}

    How craters wear down from their fresh shape with age.

    source_resolves_px

    number, optional · default 4.0 · unit px

    Source cells across from which the source's data already holds the craters (the smaller of this and completeness when both are set), by their diameter: only smaller ones are added, each raster of a chain giving its own limit. Ignored on synthetic sources and where no raster has data; null adds them all. Must be positive.

    spacing: Keeps craters of similar size apart by removing conflicting ones, which lowers the density below the model's.
    diameter_ratio

    number · default 1.5

    Largest ratio of two craters' diameters for them to count as similar in size and be kept apart. Must be at least 1.

    separation

    number · default 0.0

    Least distance between the centers of similar-size craters, in larger diameters; 0 disables spacing. Must not be negative.

    manual[]: Craters placed by hand in the surface's coordinates, added to any generated ones.
    x

    number · default 0.0

    Center along x in the surface's coordinates; the longitude in degrees on a sphere.

    y

    number · default 0.0

    Center along y in the surface's coordinates; the latitude in degrees on a sphere.

    diameter_m

    number · default 0.0 · unit m

    Rim-to-rim diameter, in meters. Must be positive.

    age_gyr

    number · default 0.0 · unit Gyr

    Age in Gyr; older craters are more degraded under a degradation model and are applied earlier in oldest-first order. Must not be negative.

    id

    integer · default 0

    Stable ID that seeds the crater's outline; 0 derives one from its position and diameter.

    depth_m

    number, optional · default null · unit m

    Rim-to-floor depth in meters, in place of the one the degradation model and age give; unset keeps the model's. Must be positive.

    rim_height_m

    number, optional · default null · unit m

    Height of the rim crest above the surface the crater formed on, in meters; needs a depth. Unset lowers the fresh rim in proportion to the depth. Must not be negative.

    replace

    boolean · default false

    Replaces whatever the terrain holds there with a sharp crater of this diameter and depth, cut into a plane fitted around it, such as a crater a DEM holds blurred; apply.replacement sets how far. It takes the irregular outline, secondaries and albedo generated craters get.

    apply: How craters are cut into the terrain: their order, datum, blending, fading and irregular outlines.
    order

    one of oldest_first, largest_first · default "oldest_first"

    Order in which overlapping craters are applied; later craters overprint earlier ones.

    fade_px

    list of number · default [...] · unit px

    How craters too small to resolve fade out, by output samples (pixels) across their diameter: absent up to the first count, whole from the second. Each must not be negative.

    fade_shape

    one of linear, smoothstep, smootherstep, gaussian · default "smoothstep"

    Curve of the fade between the two sample counts of fade_px.

    datum

    one of none, plane, mean_height, center_height · default "none"

    Reference surface each crater's interior is cut relative to, fitted to the ground beneath it; none adds craters onto the terrain everywhere.

    datum_fit_radii

    number · default 1.0

    Radius of the footprint the datum is fitted over, in crater radii. Must be positive.

    interior_replacement

    number · default 0.0

    Share of the interior replaced by datum plus profile: 1 erases older relief inside the crater for a clean cut, 0 keeps it on the floor and walls. Must be from 0 to 1.

    blend: Where and how a crater's replaced interior blends into the surrounding terrain.
    start_radii

    number · default 0.8

    Distance from the center, in crater radii, up to which the interior is fully replaced. Must not be negative.

    end_radii

    number · default 1.2

    Distance from the center, in crater radii, from which the surrounding terrain is draped unchanged. Must be positive.

    shape

    one of linear, smoothstep, smootherstep, gaussian · default "smootherstep"

    Curve of the transition from the replaced interior to the exterior.

    replacement: How manual craters with replace set replace the terrain beneath them, whatever the datum: in full to start_radii, blending out to end_radii, on a plane fitted on a ring beyond.
    start_radii

    number · default 1.0

    Distance from the center, in crater radii, up to which a replacing crater replaces the terrain in full. Must be positive.

    end_radii

    number, optional · default null

    Distance from the center, in crater radii, from which nothing is replaced; at most the profile's reach, and unset for that reach, so the replaced crater's rim goes too. Must be positive.

    fit_width_radii

    number · default 1.0

    Width, in crater radii, of the ring outside end_radii that the replacing crater's plane datum is fitted on. Must be positive.

    irregularity: Irregular, non-circular crater outlines: which craters have them and how their shapes are drawn.
    enabled

    boolean · default false

    Gives eligible craters irregular, non-circular outlines; off keeps every crater round.

    seed

    integer, optional · default null

    Seed the outlines are drawn with, along with each crater's ID; changing it reshapes every irregular crater. Unset follows the layer's seed.

    min_diameter_m

    number · default 0.0 · unit m

    Smallest diameter, in meters, of craters made irregular. Must not be negative.

    max_diameter_m

    number, optional · default null · unit m

    Largest diameter, in meters, of craters made irregular; unset has no upper limit. Must not be negative.

    min_age_gyr

    number · default 0.0 · unit Gyr

    Youngest age, in Gyr, of craters made irregular. Must not be negative.

    max_age_gyr

    number, optional · default null · unit Gyr

    Oldest age, in Gyr, of craters made irregular; unset has no upper limit. Must not be negative.

    manual

    boolean · default false

    Makes manual craters irregular too; otherwise only generated and replacing craters are.

    rough_share

    number · default 1.0

    Share of eligible craters given rough, wavy rims. Must be from 0 to 1.

    model

    one of power_law, du_2024 · default "power_law"

    How rough rims are drawn.

    scatter

    boolean · default true

    With du_2024, scatters each crater's spectrum by the fits' measured misfits and noise.

    max_deviation

    number · default 0.3

    With du_2024, the largest deviation of a rim from a circle, in radii; outlines beyond it are scaled down to it. Must be above 0 and at most 0.5.

    min_harmonic

    integer · default 2

    With power_law, the lowest harmonic of the rim's waviness. Must be from 1 to 64.

    max_harmonic

    integer · default 12

    With power_law, the highest harmonic of the rim's waviness; higher harmonics add finer wiggles. Must be from 1 to 64.

    elongated_share

    number · default 0.054

    Share of eligible craters made elliptical, keeping their area. Must be from 0 to 1.

    heading_deg

    number, optional · default null · unit deg

    Heading of elliptical craters' long axes, in degrees counter-clockwise from +x (local east on a body); unset gives random headings.

    heading_spread_deg

    number · default 0.0 · unit deg

    Largest random turn of a long axis either way from the heading, in degrees. Must not be negative.

    marks_share

    number · default 0.0

    Share of eligible craters given radial marks: ridges and grooves down the wall, strongest where it is steepest. Must be from 0 to 1.

    marks_knots

    integer · default 45

    Random shifts around the crater the marks pass through; more knots give narrower marks. Must be from 3 to 1024.

    marks_inner_radii

    number · default 0.3

    Distance from the center, in crater radii, where the marks reach full strength. Must be above 0 and below 1.

    marks_outer_radii

    number · default 0.9

    Distance from the center, in crater radii, where the marks start to fade; at most 1 minus marks_fade_radii. Must be above 0 and below 1.

    marks_fade_radii

    number · default 0.1

    Width, in crater radii, over which the marks fade in and out. Must be above 0 and at most 0.5.

    roughness: With power_law, the RMS deviation of a rough rim from a circle, in crater radii, drawn per crater.
    kind

    one of constant, uniform, normal, log_normal, piecewise · default "constant"

    Kind of distribution the value is drawn from.

    a

    number · default 0.0

    The constant value, the uniform's lower bound, the normal's mean or the log-normal's median.

    b

    number · default 0.0

    The uniform's upper bound, or the standard deviation (of the natural logarithm for a log-normal); unused for a constant.

    min

    number, optional · default null

    Lower bound drawn values are clamped to; unset leaves them unbounded below.

    max

    number, optional · default null

    Upper bound drawn values are clamped to; unset leaves them unbounded above, which normal and log-normal kinds do not allow.

    edges

    list of number · default []

    With piecewise, the edges of the bins, at least two and strictly increasing; values are uniform within each bin. Empty for every other kind.

    weights

    list of number · default []

    With piecewise, the relative weight of each bin, one fewer than the edges and not all zero; each bin draws its share of the total. Empty for every other kind. Each must not be negative.

    spectral_slope: With power_law, the exponent s of the rim harmonics' amplitudes, falling as k^-s, drawn per crater; higher values leave less fine waviness.
    kind

    one of constant, uniform, normal, log_normal, piecewise · default "constant"

    Kind of distribution the value is drawn from.

    a

    number · default 0.0

    The constant value, the uniform's lower bound, the normal's mean or the log-normal's median.

    b

    number · default 0.0

    The uniform's upper bound, or the standard deviation (of the natural logarithm for a log-normal); unused for a constant.

    min

    number, optional · default null

    Lower bound drawn values are clamped to; unset leaves them unbounded below.

    max

    number, optional · default null

    Upper bound drawn values are clamped to; unset leaves them unbounded above, which normal and log-normal kinds do not allow.

    edges

    list of number · default []

    With piecewise, the edges of the bins, at least two and strictly increasing; values are uniform within each bin. Empty for every other kind.

    weights

    list of number · default []

    With piecewise, the relative weight of each bin, one fewer than the edges and not all zero; each bin draws its share of the total. Empty for every other kind. Each must not be negative.

    ellipticity: Long over short rim-to-rim diameter of elliptical craters, drawn per crater; at least 1.
    kind

    one of constant, uniform, normal, log_normal, piecewise · default "constant"

    Kind of distribution the value is drawn from.

    a

    number · default 0.0

    The constant value, the uniform's lower bound, the normal's mean or the log-normal's median.

    b

    number · default 0.0

    The uniform's upper bound, or the standard deviation (of the natural logarithm for a log-normal); unused for a constant.

    min

    number, optional · default null

    Lower bound drawn values are clamped to; unset leaves them unbounded below.

    max

    number, optional · default null

    Upper bound drawn values are clamped to; unset leaves them unbounded above, which normal and log-normal kinds do not allow.

    edges

    list of number · default []

    With piecewise, the edges of the bins, at least two and strictly increasing; values are uniform within each bin. Empty for every other kind.

    weights

    list of number · default []

    With piecewise, the relative weight of each bin, one fewer than the edges and not all zero; each bin draws its share of the total. Empty for every other kind. Each must not be negative.

    marks_amplitude: Largest radial shift of the wall by the marks, in crater radii, drawn per crater; below marks_fade_radii / 3.75.
    kind

    one of constant, uniform, normal, log_normal, piecewise · default "constant"

    Kind of distribution the value is drawn from.

    a

    number · default 0.0

    The constant value, the uniform's lower bound, the normal's mean or the log-normal's median.

    b

    number · default 0.0

    The uniform's upper bound, or the standard deviation (of the natural logarithm for a log-normal); unused for a constant.

    min

    number, optional · default null

    Lower bound drawn values are clamped to; unset leaves them unbounded below.

    max

    number, optional · default null

    Upper bound drawn values are clamped to; unset leaves them unbounded above, which normal and log-normal kinds do not allow.

    edges

    list of number · default []

    With piecewise, the edges of the bins, at least two and strictly increasing; values are uniform within each bin. Empty for every other kind.

    weights

    list of number · default []

    With piecewise, the relative weight of each bin, one fewer than the edges and not all zero; each bin draws its share of the total. Empty for every other kind. Each must not be negative.

    rim_smoothing: Rounded rims: each crater's profile smoothed across distance near its rim; off unless sigma_radii is set.
    sigma_radii

    number · default 0.0

    Deviation of the Gaussian the profile is smoothed with across distance, in crater radii; larger values round rims more, and 0 leaves them sharp. Must not be negative.

    inner_radii

    number · default 0.8

    Inner edge of the smoothed band around the rim, in crater radii. Must be from 0 to below 1.

    outer_radii

    number · default 1.2

    Outer edge of the smoothed band around the rim, in crater radii. Must be above 1.

    shape

    one of linear, smoothstep, smootherstep, gaussian · default "smootherstep"

    How the smoothing fades from full at the rim to none at the band's edges.

    strength

    number · default 1.0

    Share of the smoothed height used at the rim; lower values keep more of the sharp crest. Must be from 0 to 1.

    noise: Fractal noise over each crater's footprint and around its rim, keyed to the crater; off unless an amplitude is set.
    amplitude

    number · default 0.0

    Amplitude of the noise over the whole footprint, as a share of the crater diameter; it fades out beyond the rim to the profile's reach, and 0 adds none. Must not be negative.

    wavelength_radii

    number · default 0.5

    Wavelength of the footprint noise's first octave, in crater radii. Must be positive.

    octaves

    integer · default 4

    Octaves of both noises. Must be from 1 to 12.

    gain

    number · default 0.5

    Weight ratio between successive octaves. Must be positive.

    rim_amplitude

    number · default 0.0

    Amplitude of the extra noise in the band around the rim, as a share of the crater diameter; 0 adds none. Must not be negative.

    rim_wavelength_radii

    number · default 0.1

    Wavelength of the rim noise's first octave, in crater radii. Must be positive.

    rim_inner_radii

    number · default 0.8

    Inner edge of the rim noise band, in crater radii. Must be from 0 to below 1.

    rim_outer_radii

    number · default 1.2

    Outer edge of the rim noise band, in crater radii. Must be above 1.

    seed

    integer, optional · default null

    Varies the noise of every crater; unset follows the layer's seed.

    texture: Gullies down fresh walls, textured ejecta and older relief buried under the ejecta; off unless an amplitude or mantling is set.
    wall_streaks

    number · default 0.0

    Amplitude of the radial gullies down a fresh crater's inner wall, as a share of its diameter; 0 adds none. Must not be negative.

    wall_streak_width_radii

    number · default 0.15

    Width of the gullies across the wall, in crater radii. Must be positive.

    ejecta

    number · default 0.0

    Amplitude of the hummocky, radially lineated ejecta around a fresh crater, as a share of the ejecta's thickness (McGetchin et al. 1973); 0 adds none. Must not be negative.

    ejecta_lineation_radii

    number · default 0.15

    Width of the ejecta's lineations across, in crater radii at the rim. Must be positive.

    mantling

    number · default 0.0

    Share of older relief buried under the ejecta at the rim, falling with their thickness; needs a datum. Must be from 0 to 1.

    ejecta_reach_radii

    number · default 3.0

    How far ejecta texture and burial reach, in crater radii. Must be above 1.

    min_freshness

    number · default 0.5

    Freshness (depth over fresh depth) at or below which gullies and ejecta texture are worn away. Must be from 0 to below 1.

    seed

    integer, optional · default null

    Varies the texture of every crater; unset follows the layer's seed.

    slope: Craters on sloping ground with floors offset downslope and rims lowered upslope; needs the plane datum.
    asymmetric

    boolean · default false

    Shapes craters asymmetrically along the slope of the ground beneath the layer; off keeps them the same on any slope.

    seed

    integer, optional · default null

    Varies how far each crater's floor is offset; unset follows the layer's seed.

    upslope_rim

    number · default 0.0

    Share of the raised rim and ejecta kept straight upslope; the rest returns toward the sides. Must be from 0 to 1.

    full_slope_deg

    number · default 5.0 · unit deg

    Slope at which the asymmetry is complete, in degrees; it rises from none on level ground. Must be positive.

    critical_gradient

    number, optional · default null

    Critical gradient Sc, rise over run, toward which downslope transport grows without bound: a crater on a regional gradient S wears 1 / (1 - (S / Sc)^2) times as fast (Roering et al. 1999). Unset wears craters alike on any slope; no lunar value is published. Must be positive.

    max_wear_rate

    number · default 10.0

    Fastest a slope makes craters wear, over level ground: a numerical cap as S nears Sc. Must be at least 1.

    floor_offset: How far the deepest point lies downslope of the center, in diameters, drawn per crater; below 0.23.
    kind

    one of constant, uniform, normal, log_normal, piecewise · default "constant"

    Kind of distribution the value is drawn from.

    a

    number · default 0.0

    The constant value, the uniform's lower bound, the normal's mean or the log-normal's median.

    b

    number · default 0.0

    The uniform's upper bound, or the standard deviation (of the natural logarithm for a log-normal); unused for a constant.

    min

    number, optional · default null

    Lower bound drawn values are clamped to; unset leaves them unbounded below.

    max

    number, optional · default null

    Upper bound drawn values are clamped to; unset leaves them unbounded above, which normal and log-normal kinds do not allow.

    edges

    list of number · default []

    With piecewise, the edges of the bins, at least two and strictly increasing; values are uniform within each bin. Empty for every other kind.

    weights

    list of number · default []

    With piecewise, the relative weight of each bin, one fewer than the edges and not all zero; each bin draws its share of the total. Empty for every other kind. Each must not be negative.

    terraces: Slump terraces on the walls of craters from the onset diameter, softening as they wear.
    enabled

    boolean · default false

    Steps the walls of large craters into slump terraces: benches and scarps between the floor and the rim crest.

    seed

    integer, optional · default null

    Varies each crater's benches, the arcs they cover and how they wander; unset follows the layer's seed.

    onset_diameter_m

    number · default 20000.0 · unit m

    Smallest terraced crater, in meters; 20 km on the Moon, where half of fresh mare craters are terraced, and about 8 km on Mars. Must be positive.

    full_diameter_m

    number · default 65000.0 · unit m

    Diameter in meters from which every crater has its most benches, over most of its wall; above the onset diameter. Must be positive.

    min_benches

    integer · default 1

    Benches at the onset diameter. Must be from 1 to 12.

    max_benches

    integer · default 4

    Benches from the full diameter; complex lunar craters usually have more than 3. Must be from 1 to 12.

    bench_slope_deg

    number · default 3.0 · unit deg

    Slope of a bench, in degrees; mapped lunar terraces slope under 5 degrees. Must be above 0 and below 45 deg.

    scarp_share

    number · default 0.25

    Least share of each step's width the scarps take; steeper steps give them more, and the bench takes the rest. Must be above 0 and below 1.

    scarp_slope_deg

    number · default 35.0 · unit deg

    Slope the scarps rise at, in degrees, above the bench slope; each step gives its scarps the share of its width that keeps them near it. Must be above 0 and below 60 deg.

    arc_share

    number · default 0.6

    Share of the wall's circumference each bench covers at the onset diameter; it rises to 0.9 at the full diameter, and 1 gives benches all the way round. Must be above 0 and at most 1.

    rim_variation

    number · default 0.08

    How far the bench radii wander around the rim, in crater radii. Must not be negative.

    block_offset

    number · default 0.6

    How far each slump block's headscarp steps from its neighbors', as a share of the room between scarps. Must be from 0 to 1.

    block_gaps

    number · default 0.25

    Share of slump blocks missing from each bench, breaking the benches into segments. Must be from 0 to below 1.

    min_freshness

    number · default 0.3

    Freshness, current over fresh depth, below which the terraces are gone; they soften as the crater wears down to it. Must be from 0 to below 1.

    peaks: Central peaks of complex craters built from massifs, lowering as the craters wear.
    enabled

    boolean · default false

    Builds the central peaks of complex craters from massifs: mountains clustered about the center in place of the profile's round dome.

    seed

    integer, optional · default null

    Varies each crater's massifs and their noise; unset follows the layer's seed.

    min_massifs

    integer · default 1

    Fewest massifs of a peak. Must be from 1 to 8.

    max_massifs

    integer · default 4

    Most massifs of a peak. Must be from 1 to 8.

    spread_radii

    number · default 0.8

    How far the lesser massifs' centers scatter from the crater's center, in peak base radii. Must be from 0 to 2.

    elongation

    number · default 2.0

    Most aspect ratio of a massif's footprint; 1 keeps them round, larger makes ridges. Must be from 1 to 4.

    chain_spread_deg

    number · default 70.0 · unit deg

    Spread of the lesser massifs' bearings about a chain through the center, in degrees: about 70 strings them across the floor, wide spreads scatter them around it into stars and crosses. Must be from 0 to 360 deg.

    sharpness

    number · default 0.6

    How sharp the massifs' crests are: 0 domes, 1 spires. Must be from 0 to 1.

    lopsidedness

    number · default 0.5

    How far each massif's summit sits off its center toward one flank. Must be from 0 to 1.

    height_variation

    number · default 0.5

    How much lower than the main massif the others may be, as a share of its height. Must be from 0 to 1.

    roughness

    number · default 0.35

    Ridged noise over the massifs, as a share of their height, carving spurs, gullies and lesser summits; worn peaks lose it. Must be from 0 to 1.

    roughness_wavelength

    number · default 0.35

    Wavelength of the massifs' noise, in peak base radii. Must be positive.

    warp

    number · default 0.12

    How far the noise warps the massifs' outlines, in peak base radii. Must be from 0 to 0.3.

    height_scale

    number · default 1.0

    The massifs' height over the profile's peak height. Must be above 0 and at most 4.

    width_scale

    number · default 1.0

    The massifs' spread and size over the profile's peak base. Must be above 0 and at most 3.

    density_map: Map that sets the crater density point by point, scaling the density's size distribution to what it measures; unset keeps the density the same everywhere.
    measure

    one of scale, count, areal_fraction · default "scale"

    What the map's values measure.

    min_diameter_m

    number · default 0.0 · unit m

    Smallest diameter the map measures, in meters; positive for a count or areal fraction. Must not be negative.

    max_diameter_m

    number, optional · default null · unit m

    Largest diameter the map measures, in meters, exclusive; unset for no limit. Must be positive.

    area_unit
