    File List¶

    Here is a list of all files with brief descriptions:

    • dir terraingen
      • file terraingen.h The whole TerrainGen library: includes every public header.
      • dir albedo
        • file albedo.h The albedo source and layer interfaces, albedo compositions and their evaluation.
        • file albedo_fields.h The field lists of the albedo options and Hapke parameters.
        • file blast_zones.h Blast zones: the regolith a lander's descent engine scoured, brighter than around it.
        • file crater_albedo.h Bright, immature ejecta, interiors and rays around fresh craters.
        • file crater_albedo_options.h The options of CraterAlbedo : retention, rays, oblique impacts, texture and the reflectance zones of new craters.
        • file maturity.h The reflectance at another optical maturity (Lucey et al.
        • file photometry.h Hapke photometry of surface materials, and the mix a material map gives.
        • file raster_albedo.h RasterAlbedo , an albedo map upscaled with fractal detail that continues its roughness.
        • file rock_albedo.h Rock albedo: boulders and the rocks too small to resolve, brighter than the regolith.
        • file slope_albedo.h Slope maturity: steep ground kept fresh, and bright, by regolith moving downslope.
        • file splotches.h Splotches: the dark and bright marks secondary impacts of loose regolith leave.
        • file synthetic.h Synthetic albedos: a base color with noise in hue, saturation and value.
      • dir analysis
        • file raster_stats.h Minimum, maximum, mean and standard deviation of a raster's valid cells, and slope statistics of a raster of heights.
        • file spectrum.h Power-law fits to the radially averaged power spectrum of a raster's heights.
        • file variogram.h Lag pairs of a raster's cells and log-log fits over lags, such as the deviogram.
      • dir config
        • file build.h Building a terrain's surface, terrain and albedo from a configuration.
        • file config.h TerrainGenConfig , a terrain configuration held as a value, and the limits configurations take.
        • file generate.h Generating the terrain a configuration describes and writing its outputs.
        • file json.h Configurations as JSON: parsing, loading, writing, catalog and schema.
        • file validate.h Checking a configuration before building it: everything parsing cannot catch.
      • dir distribution
        • file distribution_fields.h The field lists of distribution segments and bands and the names of the published distributions' variants.
        • file equilibrium.h The Trask (1966) and Hartmann (1984) lunar crater equilibrium densities.
        • file golombek_rapp.h Boulder sizes after Golombek and Rapp (1997), from the fraction of ground boulders cover.
        • file ivanov.h Ivanov's (2001) Martian chronology and production function.
        • file log_polynomial.h Size-frequency distributions given by a polynomial in log diameter.
        • file minimum.h The pointwise minimum of size-frequency distributions.
        • file moore.h Moore's lunar terrain crater distributions for Lunar Roving Vehicle trafficability.
        • file neukum.h The Neukum et al.
        • file piecewise_power_law.h Size-frequency distributions made of power-law segments.
        • file piecewise_uniform.h Size-frequency distributions made of bands with diameters spread uniformly.
        • file power_law.h Power-law size-frequency distributions and their segments.
        • file production_surface.h The crater density of a surface of a given age: a production function times a chronology.
        • file size_frequency.h The size-frequency distribution base class, its kinds and diameter ranges.
        • file sp8023.h NASA SP-8023 lunar block size distributions, digitized.
        • file spliced.h Size-frequency distributions spliced from others over consecutive diameter intervals.
        • file summed.h Weighted sums of size-frequency distributions.
        • file synthterrain.h The boulder size distributions synthterrain offers.
        • file tabulated.h Size-frequency distributions given as tables, interpolated in log-log space.
        • file viper.h The VIPER environmental specification's crater distribution.
      • dir geometry
        • file cells.h Surface cells for per-cell feature generation: planar squares and cube-sphere cells.
        • file geometry.h Small vector types, vector math and axis-aligned boxes.
        • file geometry_fields.h The field list of a box.
        • file plane_fit.h Plane andPlaneFit , a least-squares plane through points added one at a time.
        • file radial_shape.h RadialShape , a star-shaped body's radius along each direction from its center.
        • file surface.h Surface , the plane, sphere, triaxial ellipsoid or shape model a terrain lies on, with local frames and distances.
      • dir gpu
        • file backend.h Evaluation backends (the CPU, Vulkan, CUDA or Metal) and the process-wide default.
        • file program.h KernelProgram , a kernel compiled for each GPU backend, andCompiledKernel .
      • dir io
        • file feature_lists.h Reading and writing crater lists and writing boulder lists as CSV or JSON, and boulder models as 3D scenes.
        • file io_fields.h The names of list formats.
        • file report_json.h Terrain reports written as JSON.
      • dir layers
        • file anchored_plane.h AnchoredPlane , the tangent plane at an anchor that planar layers lay features out in.
        • file bedforms.h BedformLayer , fields of wind-blown ripples or dunes.
        • file bedforms_fields.h The field lists of bedforms, sand shadows and sand fill.
        • file density_map.h Density maps: how a map of feature counts or cover sets a layer's local density.
        • file dunes.h DuneLayer , dune fields of barchans, domes or crest-line dunes, with ripples on them.
        • file dunes_fields.h The field lists of dunes, their ripples and grainflows, and the names of dune shapes.
        • file evaluation_cache.h EvaluationCache , values one evaluation's batches of points share.
        • file exposure.h ExposureField , how far the ground is bare bedrock rather than soil, andPatchNoise .
        • file fade.h Falloff curves, and the fade of features too small to resolve at a sample spacing.
        • file field.h Scalar fields over a surface, such as density maps and catalog completeness limits.
        • file ground.h The terrain beneath a layer, readable at any point.
        • file layer.h Layer , relief added on top of a source, andFormulaLayer for point-wise layers.
        • file layer_fields.h Field lists shared by layers: fades, exposure, selections, anchors, raster fields, density maps, roughness and spectral continuation, and the names of their enums.
        • file masked.h MaskedLayer , another layer applied only inside a rectangle, circle or polygon.
        • file material.h Surface material classes, and MaterialSource , the layers that lay one down.
        • file noise_layer.h NoiseLayer , a stack of fractals added to the terrain.
        • file pavement.h PavementLayer , fractured bedrock: polygonal plates parted by cracks or raised ridges.
        • file pavement_fields.h The field lists of pavement and strata.
        • file roughness.h RoughnessLayer , fine self-affine roughness from octaves of Perlin noise.
        • file roughness_estimate.h Self-affine roughness of a base's heights by the variogram method, for layers that continue it below the base's resolution.
        • file sand_fill.h SandFillLayer , sand pooled in the lows of the ground beneath it.
        • file sand_shadow.h SandShadowLayer , sand tails in the lee of a boulder layer's boulders.
        • file source_resolved.h The feature size from which a source's measured data already holds a layer's features.
        • file spectral_continuation.h SpectralContinuationLayer , detail finer than a base DEM that continues the base's measured power-law spectrum (EstimatePowerLawSpectrum ).
        • file strata.h StrataLayer , layered rock: the ground beneath terraced into benches and cliffs.
        • file terrain_base.h TerrainBase , the surface and source crater and boulder layers are built on.
        • dir boulders
          • file boulder.h Boulder , the record of one placed boulder,BoulderList of many, andManualBoulder , one placed by hand.
          • file boulder_abundance.h How abundant a BoulderLayer 's boulders are: density maps, patches, crater blocks and the candidates thinning starts from.
          • file boulder_fields.h The field lists of boulder layers, boulder shapes and manual boulders, and the names of their enums.
          • file boulder_fragments.h Boulder shapes split into pieces that fit back together.
          • file boulder_layer.h BoulderLayer , boulders scattered over the ground and around fresh craters.
          • file boulder_models.h Boulders as 3D models: placing unit shapes on the ground, and their meshes.
          • file boulder_options.h How a BoulderLayer sizes, places, poses and draws its boulders.
          • file boulder_placer.h BoulderPlacer , a layer that lists the boulders it places.
          • file boulder_shape.h Procedural boulder meshes: styles, shape options and seeded shape generation.
          • file ejecta_index.h EjectaIndex , craters bucketed by the discs their ejecta reach.
        • dir craters
          • file band_buckets.h BandBuckets , indices bucketed by size band and surface position for neighbor searches.
          • file crater.h Crater andCraterList , andCraterSelection , which of them a model applies to.
          • file crater_fields.h The field lists of craters, their generation, shaping and secondaries, and the crater enum names.
          • file crater_layer.h CraterLayer , craters generated over the grid being evaluated and applied to it.
          • file crater_placer.h CraterPlacer , a layer that lists the craters it applies.
          • file rays.h The directions of a crater's rays, shared by its secondaries and its bright streaks.
          • file secondaries.h SecondaryCraterLayer , secondary craters around the craters of aCraterLayer .
          • file secondary_model.h The laws secondary craters follow, their options, and their density around a primary.
          • dir ages
            • file age_model.h CraterAgeModel , crater ages by diameter, and the simplest:FreshAges ,UniformAges .
            • file freshness_ages.h FreshnessAges , crater ages from a distribution of freshness.
            • file steady_state.h Crater ages on surfaces where small craters are in equilibrium.
          • dir degradation
            • file degradation_model.h DegradationModel , which maps craters to their degradation state, andNoDegradation .
            • file diffusion.h Crater degradation by topographic diffusion: DiffusedProfile ,DiffusionDegradation .
            • file diffusivities.h Lunar topographic diffusivities of Fassett and Thomson (2014) and Fassett et al.
            • file freshness_degradation.h FreshnessDegradation , craters degraded linearly with the share of their lifetime left.
            • file state.h A crater's shape measures and degradation state.
          • dir generation
            • file population.h Generating crater populations cell by cell, in size bands.
            • file spacing.h Keeping craters of similar size apart: conflicts, precedence and thinning.
          • dir profiles
            • file complex.h ComplexCraterProfile : flat floors, concave walls and central peaks;CraterTerraces steps the walls into slump terraces.
            • file fassett_thomson.h The fresh simple-crater profile of Fassett and Thomson (2014) and its rim variants.
            • file martin_parkes_dunstan.h The simple-crater profile of Martin, Parkes and Dunstan (2014).
            • file profile.h CraterProfile , a crater's height as a function of distance from its center.
          • dir shaping
            • file apply.h Applying a list of craters to heights, over a raster or at scattered points.
            • file apply_options.h How craters are applied to the terrain: their order, datum, blend, outlines and rims.
            • file attributes.h CraterAttributes , what a crater looks like in its current state.
            • file datum.h Crater datums, the surfaces crater interiors are cut to, fitted to the ground.
            • file irregularity.h Irregular, non-circular crater outlines: elongation and rough rims.
            • file morphometry.h Fresh crater morphometry and complex crater shapes fitted to the Moon and Mars.
            • file prepared.h PreparedCrater , a crater with everything needed to shape it at one sample spacing.
            • file slope.h Craters formed on slopes: floors offset downslope and raised rims lowered upslope.
        • dir kernels
          • file cell.h CellPosition , where a kernel evaluates; a kernel header for C++ and Slang.
          • file craters.h The kernel of crater shaping ( ApplyCraters ); a kernel header for C++ and Slang.
          • file noise_layer.h The kernel of NoiseLayer ; a kernel header for C++ and Slang.
        • file transforms.h Height transforms as layers: scale and offset, clamp, and a function of your own.
      • dir mesh
        • file mesh.h Triangle meshes, their measures, normals and rigid transforms.
        • file mesh_build.h BuildMesh , a grid of heights as a triangle mesh, andFillMesh into caller buffers.
        • file polyhedra.h Base solids for boulders and midpoint subdivision.
        • file shape_model.h ShapeModelFromMesh , a body's shape model mesh as aRadialShape .
        • dir io
          • file icq.h Gaskell's implicitly connected quadrilateral (ICQ) shape models: reading, writing and triangulating them.
          • file mesh_io.h Reading and writing triangle meshes and instanced scenes as OBJ with MTL, glTF and STL.
      • dir noise
        • file fractal.h Fractals (fBm, ridged, billow, hybrid) built from octaves of a basis noise.
        • file fractals.h Stacks of fractals with domain warps and blend modes.
        • file hash.h Stateless PCG hashes for the CPU and GPU backends ( portable.h ).
        • file lattice.h Points split into a lattice cell and a fraction, interpolation helpers, and the frozen lattice hash keys.
        • file noise_fields.h The field lists of fractals and the names of the noise enums.
        • file perlin.h Improved Perlin gradient noise in 2D and 3D.
        • file simplex.h Simplex noise in 2D and 3D.
        • file structure_function.h Structure functions of Perlin noise: the mean squared difference of values a lag apart.
        • file surface_noise.h Fractal stacks evaluated at points of a plane or a body's surface.
        • file validate.h Host-side checks of fractal parameters and fractal stacks before kernels use them.
        • file value.h Value noise in 2D and 3D.
        • file worley.h Worley cellular noise in 2D and 3D: feature-point distances and Voronoi cell values.
      • dir pipeline
        • file body_mesh.h BodyMesh andBodyIcq , the whole body a terrain on a sphere or ellipsoid lies on.
        • file materials.h Material maps of a terrain: the share of soil, sand, dust, bedrock and rock at each point.
        • file materials_fields.h The field list of material options.
        • file report.h Terrain reports: statistics of evaluated grids, layer timings and run details.
        • file terrain.h Terrain , a surface, optional starting heights and layers, evaluated over grids or at points, updated in place and reseeded.
        • file terrain_view.h TerrainView , a terrain's heights over one grid, updated as the terrain is edited.
      • dir random
        • file philox.h The Philox4x32-10 counter-based generator for the CPU and GPU backends.
        • file random_fields.h The field list of value distributions and the names of their kinds.
        • file samplers.h Samplers for Poisson and normal distributions.
        • file stream.h RandomStream , a counter-based random number stream, derived seeds and 64-bit IDs.
        • file streams.h Every random stream tag: the word that keys RandomStream andSubstreamSeed apart for one purpose.
        • file value_distribution.h ValueDistribution , a clamped distribution a parameter is drawn from.
      • dir raster
        • file cell_loops.h Parallel loops over a raster's cells: every cell, or the windows around features.
        • file geo_transform.h The affine pixel-to-world transform of a georeferenced raster.
        • file grid.h Raster grids without values, and resampled grids and spacings derived from them.
        • file raster.h A single-band georeferenced grid of values.
        • file raster_fields.h The names of the interpolation methods and TIFF compressions.
        • file resample.h Interpolation of rasters: nearest, bilinear, cubic, Lanczos and B-spline.
        • dir geotiff
          • file geotiff.h Reading and writing GeoTIFF rasters, with their projection keys and band scaling.
      • dir sources
        • file diamond_square.h DiamondSquareUpsampler , random midpoint displacement (diamond-square) refinement of a source's posts, as Martin, Parkes and Dunstan (2014) expand DEMs.
        • file flat_source.h A source of constant elevation, the start of a fully synthetic terrain.
        • file geotiff_source.h Heights read from a band of a GeoTIFF DEM.
        • file raster_source.h Heights from a raster held in memory.
        • file sample_block.h Positions a source or layer evaluates and their heights: a raster's cells or scattered points.
        • file shape_model_source.h ShapeModelSource , a shape-model body's own labels refined by an upsampler.
        • file source.h The source interface: where a terrain's heights come from.
        • file source_chain.h Sources tried in order, each filling the gaps of those before it.
        • file sources_fields.h The field lists of diamond-square options, chain seams and GeoTIFF band reads, and the names of their enums.
        • file synthetic_source.h SyntheticSource , heights generated from a stack of fractals over an unbounded plane or a whole body.
        • file upsampling.h Upsamplers: how a source's posts become heights at any point and sample spacing.
      • dir util
        • file bits.h Pi, bit casts, byte order and integer arithmetic, in C++17.
        • file build_info.h Build metadata of the linked library.
        • file log.h Leveled logging to a replaceable sink, and timing helpers for log messages.
        • file lru_cache.h LruCache , a sharded thread-safe least-recently-used cache.
        • file option_fields.h Field lists of option structs: ranges, enum names and the range check they share.
        • file parallel.h A parallel for loop over a shared thread pool.
        • file portable.h Prelude that compiles kernel headers, written in the subset of C++ that Slang accepts, both as C++ (CPU) and as Slang (GPU); KERNEL_IN(T) passes a struct by reference in C++ only.
        • file span.h Span , a non-owning view of contiguous elements that keeps the library at C++17.
        • file special_functions.h Special functions the models need: the exponential integral.
