    Quickstart¶

    This page makes a first terrain in two ways, from a configuration file on the command line and one layer at a time from Python or C++. Every example on it is run as a test, and every image is made by the code above it.

    Install the Python package, which also installs the terraingen command. See Installation for releases and building from source.

    pip install terraingenpy

    From the command line¶

    A configuration is JSON that describes a terrain's layers, applied in order, and the files to write. This one lays fractal noise, craters and boulders over a 128 m square and writes a GeoTIFF of the heights at 0.5 m and a list of the craters.

    config.json
    {
    "schema_version": 1,
    "layers": [
        {"type": "noise", "stack": [{"wavelength_m": 80, "amplitude_m": 2, "octaves": 5}]},
        {"type": "craters", "min_diameter_m": 3, "max_diameter_m": 60},
        {"type": "boulders", "min_diameter_m": 0.5, "max_diameter_m": 3}
    ],
    "outputs": [
        {
            "type": "heightmap",
            "path": "terrain.tif",
            "pixel_size_m": 0.5,
            "extent_m": {"center": [0, 0], "size": [128, 128]}
        },
        {
            "type": "crater_list",
            "path": "craters.csv",
            "pixel_size_m": 0.5,
            "extent_m": {"center": [0, 0], "size": [128, 128]}
        }
    ]
}

    Generate it from the command line.

    terraingen config.json

    Python runs the same file without the command.

    config = terraingen.load_config(CONFIG)
generated = terraingen.generate_from_config(config)
terraingen.write_outputs(config, generated, output_folder)  # terrain.tif and craters.csv

    The configuration reference lists every layer and output and their settings.

    From Python or C++¶

    The same terrain can be built from library objects, one layer at a time. Python needs only import terraingen; C++ includes terraingen/terraingen.h and links terraingen::terraingen.

    Craters on a flat source¶

    A terrain is a source of starting heights and layers applied over it, on a surface, a plane by default. Here the source is flat, 257 x 257 cells of 0.5 m, and one crater layer draws craters from the lunar production function, aged and worn.

    source = terraingen.FlatSource(257, 257, 0.5)  # 257 x 257 cells of 0.5 m
craters = terraingen.CraterLayer()
terrain = terraingen.Terrain(source=source, layers=[craters])  # on a plane
heights = terrain.evaluate()  # a Raster in meters; .values is a NumPy array

    const auto source = std::make_shared<FlatSource>(257, 257, 0.5);  // 257 x 257 cells of 0.5 m
const auto craters = std::make_shared<CraterLayer>();
const Terrain terrain(Surface{}, source, {craters});  // on a plane
const Raster<float> heights = terrain.Evaluate();     // meters

    Noise beneath the craters¶

    Layers apply in order, each on the heights before it, so noise placed first lies beneath the craters.

    noise = terraingen.NoiseLayer(seed=1, wavelength=80.0, amplitude=2.0, octaves=5)
craters = terraingen.CraterLayer()
terrain = terraingen.Terrain(source=source, layers=[noise, craters])  # layers apply in order

    Fractal fractal = Fractal::Fbm(1, 80.0, 2.0);  // seed, wavelength and amplitude in meters
fractal.octaves = 5;
const auto noise = std::make_shared<NoiseLayer>(fractal);
const auto craters = std::make_shared<CraterLayer>();
const Terrain terrain(Surface{}, source, {noise, craters});  // layers apply in order

    Boulders¶

    A boulder layer scatters boulders between the craters and, given the crater layer, throws ejecta blocks around them. Boulders smaller than a cell are left out of the heights, and the largest can be written as 3D models instead.

    boulders = terraingen.BoulderLayer(craters=craters)  # with ejecta thrown out by those craters
terrain = terraingen.Terrain(source=source, layers=[noise, craters, boulders])

    // With ejecta thrown out by those craters.
const auto boulders = std::make_shared<BoulderLayer>(BoulderLayerOptions{}, craters);
const Terrain terrain(Surface{}, source, {noise, craters, boulders});

    Albedo¶

    An albedo is a source of reflectance changed by albedo layers. Here a synthetic base of mature soil is brightened around fresh craters, which fade as they age. It reads the crater layer, not the heights, so it needs no evaluation.

    base = terraingen.SyntheticAlbedo(value=0.11)  # mature mare soil at 750 nm
albedo = terraingen.Albedo(base, [terraingen.CraterAlbedo(craters)])
(reflectance,) = terraingen.evaluate_albedo(albedo, source.grid())  # one band

    SyntheticAlbedoOptions base;
base.value = 0.11;  // mature mare soil at 750 nm
Albedo albedo;
albedo.source = std::make_shared<SyntheticAlbedo>(base);
albedo.layers = {std::make_shared<CraterAlbedo>(craters)};
const std::vector<Raster<float>> bands = EvaluateAlbedo(albedo, source->Grid(), {});

    Write the outputs¶

    Write the heights as a GeoTIFF, and the craters and boulders the layers placed as lists.

    terraingen.write_geotiff("terrain.tif", heights, terrain.keys())
terrain.craters().write_list("craters.csv")
terrain.boulders().write_list("boulders.csv")

    WriteGeoTiff("terrain.tif", heights, terrain.Keys());
const RasterGrid grid = heights.Grid();
WriteCraterList(terrain.Craters(grid).craters, "craters.csv", ListFormat::Csv);
WriteBoulderList(terrain.Boulders(grid).boulders, "boulders.csv", ListFormat::Csv);
