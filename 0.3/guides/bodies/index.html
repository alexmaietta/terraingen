    Irregular bodies¶

    Make a Body From a Shape Model File¶

    A shape model makes a whole star-shaped body such as an asteroid. Points on it are planetocentric longitude and latitude in degrees, and heights are measured along the direction from its center. An ICQ model, such as Gaskell's for Itokawa or Eros from the PDS Small Bodies Node, keeps its own Q. A closed mesh (.obj, .gltf, .glb or .stl) around its origin is resampled along rays from the origin at Q intervals per cube face edge. Where a ray crosses the surface more than once, the outermost crossing is kept.

    model = terraingen.read_icq(folder / "rock.icq")  # Gaskell's ICQ models are in kilometers
body = terraingen.Surface.shape_model(model.to_radial_shape())
mesh = terraingen.read_mesh(folder / "rock.obj").mesh  # closed around its origin, in meters
from_mesh = terraingen.Surface.shape_model(terraingen.shape_model_from_mesh(mesh, 64))

    const IcqModel model = ReadIcq(folder / "rock.icq");  // Gaskell's ICQ models are in kilometers
const Surface body = Surface::ShapeModel(std::make_shared<RadialShape>(ToRadialShape(model)));
const TriangleMesh mesh = ReadMesh(folder / "rock.obj").mesh;  // closed, in meters
const Surface fromMesh =
    Surface::ShapeModel(std::make_shared<RadialShape>(ShapeModelFromMesh(mesh, 64)));

    Make a Body From a Radius Function¶

    A body can come from any radius by direction. The function is sampled at every label of a radial grid of Q intervals per cube face edge, and the body interpolates between them. Here an ellipsoid 540 by 300 by 210 m has five lobes around its equator.

    def radius(u):  # meters along the unit direction u, x toward 0 E and z north
    ellipsoid = 1.0 / math.sqrt((u[0] / 270.0) ** 2 + (u[1] / 150.0) ** 2 + (u[2] / 105.0) ** 2)
    return ellipsoid * (1.0 + 0.04 * math.sin(5.0 * math.atan2(u[1], u[0])))

shape = terraingen.RadialShape.sample(64, radius)  # 64 intervals per cube face edge
body = terraingen.Surface.shape_model(shape)

    const auto radius = [](const Vec3d& u) {  // meters along the unit direction u
    const double ellipsoid =
        1.0 / std::sqrt(std::pow(u.x / 270.0, 2) + std::pow(u.y / 150.0, 2) +
                        std::pow(u.z / 105.0, 2));
    return ellipsoid * (1.0 + 0.04 * std::sin(5.0 * std::atan2(u.y, u.x)));
};
const auto shape = std::make_shared<RadialShape>(RadialShape::Sample(64, radius));
const Surface body = Surface::ShapeModel(shape);

    Upsample a Shape Model¶

    A shape model is the body and also its terrain's source. On its own the body interpolates its labels bilinearly, which leaves flat facets between them. A ShapeModelSource treats the labels as posts and refines them with any upsampler, as a DEM's cells are refined. Its heights are the refined radius less the bilinear one, 0 on every label. Kernel upsamplers such as cubic or Lanczos smooth between the labels. Diamond-square adds fractal detail below their spacing, with a roughness fitted to them unless given. Each cube face's posts are read across its edges and the faces are blended within half a label of them, so there are no seams. Layers then add to the refined shape, and treat it as measured data that they need not add again.

    cubic = terraingen.ShapeModelSource(body)  # cubic between the labels by default
lanczos = terraingen.ShapeModelSource(
    body, terraingen.KernelUpsampler(terraingen.ResampleMethod.LANCZOS3)
)
# Diamond-square with a roughness fitted to the labels.
rough = terraingen.ShapeModelSource(body, terraingen.DiamondSquareUpsampler())
terrain = terraingen.Terrain(body, rough)
site = terraingen.RasterGrid.covering((20.0, 10.0, 30.0, 20.0), 0.05)  # longitude and latitude, degrees
heights = terrain.evaluate(site, spacing=0.25)  # meters above the bilinear shape

    const auto cubic = std::make_shared<ShapeModelSource>(body);  // cubic between the labels
const auto lanczos = std::make_shared<ShapeModelSource>(
    body, std::make_shared<KernelUpsampler>(ResampleMethod::Lanczos3));
const auto rough = std::make_shared<ShapeModelSource>(
    body, std::make_shared<DiamondSquareUpsampler>());  // roughness fitted to the labels
const Terrain terrain(body, rough, {});
const RasterGrid site = RasterGrid::Covering({20.0, 10.0, 30.0, 20.0}, 0.05);  // degrees
// Meters above the bilinear shape.
const Raster<float> heights = terrain.Evaluate(site, EvaluationOptions{}.Spacing(0.25));

    Add Relief, Craters and Boulders Over a Whole Body¶

    Layers on a body cover all of it. The terrain takes the body as its surface, here with the shape upsampled as its source, and the crater and boulder layers take it as their base. Noise is 3D at each point, so it has no seams, and craters and boulders are drawn per cube-face cell by that cell's true area. Grids and regions are longitude and latitude in degrees, and spacings are meters. Here fresh craters from 3 m to 40 m and boulders from 1 m to 15 m cover a lumpy body about 600 m long.

    relief = terraingen.NoiseLayer(seed=5, wavelength=40.0, amplitude=0.6, octaves=4)
defaults = terraingen.default_crater_models()
models = terraingen.CraterModels(
    terraingen.PowerLawSfd(0.05, 2.0), terraingen.FreshAges(), defaults.degradation, defaults.profile
)
generation = terraingen.CraterGenerationOptions(min_diameter=3.0, max_diameter=40.0)  # meters
craters = terraingen.CraterLayer(
    models, terraingen.CraterLayerOptions(seed=6, generation=generation), base=body
)
sizes = terraingen.BoulderSizes(distribution=terraingen.PowerLawSfd(0.05, 2.5))
sizes.min_diameter, sizes.max_diameter = 1.0, 15.0
boulders = terraingen.BoulderLayer(
    terraingen.BoulderLayerOptions(sizes=sizes, seed=7), craters, base=body
)
terrain = terraingen.Terrain(body, terraingen.ShapeModelSource(body), [relief, craters, boulders])

whole = (-180.0, -90.0, 180.0, 90.0)  # longitude and latitude, degrees
heights = terrain.evaluate(terraingen.RasterGrid.covering(whole, step), spacing=0.5)
listed = craters.craters(whole, 0.5)  # every crater on the body

    Fractal fractal = Fractal::Fbm(5, 40.0, 0.6);  // seed, wavelength and amplitude in meters
fractal.octaves = 4;
const auto relief = std::make_shared<NoiseLayer>(fractal);
CraterModels models = DefaultCraterModels();
models.density = std::make_shared<PowerLawSfd>(0.05, 2.0);
models.ages = std::make_shared<FreshAges>();
CraterLayerOptions craterOptions;
craterOptions.seed = 6;
craterOptions.generation.minDiameter = 3.0;  // meters
craterOptions.generation.maxDiameter = 40.0;
const auto craters = std::make_shared<CraterLayer>(models, craterOptions, body);
BoulderLayerOptions boulderOptions;
boulderOptions.seed = 7;
boulderOptions.sizes.distribution = std::make_shared<PowerLawSfd>(0.05, 2.5);
boulderOptions.sizes.minDiameter = 1.0;
boulderOptions.sizes.maxDiameter = 15.0;
const auto boulders = std::make_shared<BoulderLayer>(boulderOptions, craters, body);
const auto shape = std::make_shared<ShapeModelSource>(body);  // the shape, upsampled by cubic
const Terrain terrain(body, shape, {relief, craters, boulders});

const Bounds2d whole{-180.0, -90.0, 180.0, 90.0};  // longitude and latitude, degrees
const Raster<float> heights =
    terrain.Evaluate(RasterGrid::Covering(whole, 10.0), EvaluationOptions{}.Spacing(0.5));
const CraterList listed = craters->Craters(whole, 0.5);  // every crater on the body

    Write the Whole Body as a Mesh or Shape Model¶

    BodyMesh meshes the whole body from the six faces of a cube, each split into cells per face edge squared quads. Every vertex sits at the body's radius plus the terrain's height there, in body-fixed meters with x toward 0 E and z north. BodyIcq samples the same terrain at the labels of an ICQ shape model, which other shape-model tools read. It works on spheres and ellipsoids as well as shape models.

    mesh = terraingen.body_mesh(terrain, 128, spacing=0.5)  # 6 x 128 x 128 quads, samples 0.5 m apart
mesh.write(output_folder / "body.glb")  # or .gltf, .obj or .stl
shape_model = terraingen.body_icq(terrain, 128, spacing=0.5)  # Q = 128
terraingen.write_icq(output_folder / "body.icq", shape_model)  # in kilometers

    const TriangleMesh mesh =
    BodyMesh(terrain, 128, 0.5);       // 6 x 128 x 128 quads, samples 0.5 m apart
WriteMesh(folder / "body.glb", mesh);  // or .gltf, .obj or .stl
const IcqModel shapeModel = BodyIcq(terrain, 128, 0.5);  // Q = 128
WriteIcq(folder / "body.icq", shapeModel);               // in kilometers

    Configure a Body From a Shape Model¶

    A configuration's body of type "shape_model" reads an ICQ model or a closed mesh. A relative path resolves against the configuration's folder. The model is also the source. Without a "source" its labels are refined by cubic interpolation, a "shape_model" source picks another upsampling, and any other source replaces it. The layers cover the whole body, and "mesh" outputs write the whole body as glTF, OBJ, STL or an ICQ model. A "crater_list" output with pixel_size_m alone lists the craters of the whole body. terraingen config.json runs the same file from the command line.

    CONFIG = {
    "schema_version": 1,
    "body": {"type": "shape_model", "path": "rock.icq"},  # or a closed .obj, .gltf, .glb or .stl
    "source": {"type": "shape_model", "upsampling": {"type": "diamond_square"}},  # cubic when left out
    "layers": [
        {
            "type": "noise",
            "stack": [{"seed": 5, "basis": "simplex", "wavelength_m": 40, "amplitude_m": 0.6, "octaves": 4}],
        },
        {
            "type": "craters",
            "seed": 6,
            "density": {"type": "power_law", "coefficient": 0.05, "exponent": 2},
            "ages": {"type": "fresh"},
            "min_diameter_m": 3,
            "max_diameter_m": 40,
        },
        {
            "type": "boulders",
            "seed": 7,
            "sizes": {"type": "power_law", "coefficient": 0.05, "exponent": 2.5},
            "min_diameter_m": 1,
            "max_diameter_m": 15,
        },
    ],
    "outputs": [
        {"type": "mesh", "path": "rock_terrain.glb", "cells_per_face": 128},
        {"type": "mesh", "path": "rock_terrain.icq", "cells_per_face": 128},
        {"type": "crater_list", "path": "rock_craters.csv", "pixel_size_m": 1},
    ],
}

    const TerrainGenConfig config = ParseConfig(R"({
    "schema_version": 1,
    "body": {"type": "shape_model", "path": "rock.icq"},
    "source": {"type": "shape_model", "upsampling": {"type": "diamond_square"}},
    "layers": [
        {"type": "noise", "stack": [{"seed": 5, "basis": "simplex", "wavelength_m": 40,
                                     "amplitude_m": 0.6, "octaves": 4}]},
        {"type": "craters", "seed": 6, "ages": {"type": "fresh"},
         "density": {"type": "power_law", "coefficient": 0.05, "exponent": 2},
         "min_diameter_m": 3, "max_diameter_m": 40},
        {"type": "boulders", "seed": 7,
         "sizes": {"type": "power_law", "coefficient": 0.05, "exponent": 2.5},
         "min_diameter_m": 1, "max_diameter_m": 15}
    ],
    "outputs": [
        {"type": "mesh", "path": "rock_terrain.glb", "cells_per_face": 128},
        {"type": "mesh", "path": "rock_terrain.icq", "cells_per_face": 128},
        {"type": "crater_list", "path": "rock_craters.csv", "pixel_size_m": 1}
    ]
})");

    config = terraingen.TerrainGenConfig.from_dict(CONFIG)
generated = terraingen.generate_from_config(config, folder)  # rock.icq is read from folder
terraingen.write_outputs(config, generated, folder)

    const GeneratedOutputs generated = GenerateFromConfig(config, folder);  // reads folder/rock.icq
WriteOutputs(config, generated, folder);
