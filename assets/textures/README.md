# Textures

Tileable detail textures for terrain materials, stored in Git LFS.

| Files | Source | License |
| --- | --- | --- |
| `moon_01_diff_4k.jpg`, `moon_01_nor_gl_4k.exr`, `moon_01_rough_4k.exr`, `moon_01_disp_4k.png` | Poly Haven, "Moon 01" by G. Zaal, R. Cilliers, J. van Heerden and D. Barresi, <https://polyhaven.com/a/moon_01> | CC0 1.0 |

The moon_01 scan covers about 3.1 m of lunar regolith per tile: diffuse colour (sRGB), OpenGL
normal map, roughness and displacement, at 4096 x 4096.
